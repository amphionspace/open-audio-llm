# 下一轮训练计划：区分音色相近的说话人（2026-10-14）

## 结论

- 重叠仿真轮不采用（2000 步 AliMeeting dev cpER 20.11，最终面板合成会议门槛未过）。10% 原版权重插值在选模面板上更好（cpER 20.34），但最终面板变差（合成中文会议 10.2 → 18.1、AISHELL-5 dev 27.8 → 30.4、AliMeeting test 21.1 → 21.6，`runs/weight-interp-20261014/tasks/03-final`），不采用。目前最好的仍是 Emilia2 6000 步。
- 与 MOSS 的差距主要在**说话人**，不在重叠处的字：AliMeeting dev（120 秒窗口，只看模型输出）按参考句统计，我们 20.2、MOSS 15.2，差距 5.0 点里约 2.1 点是说话人归错，2.9 点是字没听对。
- 说话人归错和**音色相近**直接相关：按窗口内最相近两人的声纹相似度分三档，我们与 MOSS 的归错差距依次是 0.9、2.2、3.9 点；MOSS 三档都在 1.5–2.6，我们从 2.4 涨到 5.9。人工听审也确认了这一点（"分不出 S1、S3 两个女声""多出一个不存在的人"）。
- 下一轮只做一件事：**用真实数据里音色相近的窗口，教模型把相近的人分开**。去掉无效的 Emilia2 重叠仿真（20%）。

## 和 MOSS 怎么比

- 只比 120 秒窗口上的模型输出（AliMeeting dev 选模面板 138 窗、AliMeeting test），不引入跨窗口关联、会话拼接等模型以外的环节。
- AISHELL-4 跨窗口关联改进移出本计划，作为部署侧的独立事项。
- 说明：训练数据里也有 30/300/600 秒窗口（真实会议的多长度切分），但对外对比统一用 120 秒。

## 步骤

### 第一步：准备（不训练，约 1–2 天）

1. **音色相近视图**：对真实中文会议训练窗口、Emilia2 未用部分，按参考说话人提取声纹（同上模型、同样只取不重叠语音），记录每窗最相近两人的相似度，取前 1/3 注册为派生视图（固定版本，标注不变）。
   - 核查：真实会议子集里同性别窗口的占比应明显高于全集，否则相似度没有抓到"像"。
   - Emilia2 标注来自 MOSS，而 MOSS 在高相似窗口上归错仍只有 2.0，可用；沿用已有的逐句说话人校验。
2. **选模口径升级**：选模器在 AliMeeting dev 上加报三项：按说话人对齐后的"字错 / 归错"拆分、高相似 1/3 窗口的归错、时间戳偏差 >1 秒比例。目标仍是 AliMeeting dev cpER（不计复读）。
3. 数据预检：配比实际生效、全量覆盖、无缺失音频。

### 第二步：训练

- 起点：Emilia2 6000 步（10% 插值模型最终面板变差，见结论）。
- 训练参数沿用前两轮（学习率 5e-6、cosine、12000 步上限、每 1000 步选模、连续 3 次门槛回退即停），只改数据，结果可以直接和前两轮对比。
- 选中的 checkpoint 直接进最终面板，不再做插值。
- W&B：训练、选模、最终面板各自接入并核验远端指标。

### 验收（AliMeeting dev，120 秒窗口，对起点）

| 指标 | 起点 | 要求 |
|---|---|---|
| 高相似 1/3 窗口的说话人归错（选模器口径：>3 字句子按字数汇总） | Emilia2 6000 步 4.0（MOSS 0.3） | 减半，≤ 2.0 |
| cpER（不计复读） | 21.52（选模器实测） | < 19.5 |
| 重叠句字错（按说话人对齐） | 实测 | 不变差超过 0.5 |
| WenetSpeech / KeSpeech dev | 3.98 / 3.99 | 各不超过 +1 |
| 6–12 人合成 cpER | 25.2 | 不超过 +5 |

### 第三步：按结果分叉

- 归错降下来、cpER 仍差 MOSS 3 点以上：剩下的是字，做 GRPO（奖励 = cpER + 复读惩罚），或用付费 API 打标更多真实会议。
- 归错没降：说明问题不在数据而在模型的说话人表征，考虑给模型接入外部声纹特征。
