# 目标说话人业务 bad case 第二批（case-08 到 case-12）

**结论：模型行为与客户引擎一致（逐字复现），5 个包里最明确的问题不在模型：case-10 是 19 秒纯音乐片段，模型输出为空（正确），用户看到的失败是引擎 286 ms 处的 `context canceled`。** 其余 4 个包没有确认的参考文本，只能说明短片段和注册音频的问题继续出现。没有训练，用已发布权重回放。

登记：audio-data-contract `business_feedback@ts-20261012`（`target_speaker` 1 条、`pending_labels` 4 条），AmphionEval `open-audio-llm/business-feedback-ts@20261012`（累计两个批次）。第一批分析见 [上一份](../2026-10-12-ts-badcase/README.md)。

## 和第一批的区别

- 同一位测试人员把设备放在固定环境里持续收音，定时查看结果，再挑出片段。
- 请求是流式（`stream: true`、`max_tokens: 256`），带 `mm_processor_kwargs: {"target_speaker": true}`；`source_revision` 为 `unknown`；trace 前缀为 `dingqiao-web`，是客户使用的引擎。
- 注册音频换成了另一段录音（5 个包共用一段，与第一批不是同一文件）。

## 回放

用发布包 `v3-34479` 的 TS 服务（vLLM 0.18.0，`serve.sh tsasr`，非流式、贪心）回放，并做注册音频对照。

- 5 个包的客户引擎输出全部被我们的服务逐字复现，所以尽管请求形式不同（带 `target_speaker` 标志、流式、`unknown` 版本），模型行为一致，没有发现服务端实现的差异。
- **case-10**：只有歌曲，没有人说话。用测试人员的注册音频，模型输出为空，是正确的；换成第一批的注册音频（同一位测试人员的另一段录音）或静音，模型会把歌词转写出来，说明歌声确实在片段里；同一个人的两段注册录音一个拒绝、一个接受，可见结果对具体的注册录音很敏感。用户看到的错误是引擎在 286 ms 处取消了流（`manifest.error = context canceled`），片段是 19 秒，应当由前端排查（超时或客户端断开），不是模型输出。
- **case-08、case-11**：片段只有 1–2 秒，输出基本不随注册音频变化（case-08 三种注册输出相同）。这与评测集的结论一致：极短片段缺席时误输出 75%，输出多是「你」「我」这类幻觉。
- **case-09**：5 秒的完整句子，在两段注册音频和静音注册下都被接受；换成 20 个随机错误说话人的注册（电平对齐）接受率为 0%。和第一批相同：这位测试人员的注册音频会接受不是他的声音（或者那句话本来就是他说的，没有标注，无法区分）。
- **case-12**：17.86 秒，所有注册下都输出空，说明片段里没有可转写的语音，或者非常弱；没有反馈。

对 20 个随机错误说话人注册（电平对齐）的接受率：case-08 20%、case-09 0%、case-11 20%、case-10 5%。

## 登记时的标签

只有 case-10 有确认的事实（「纯播放音乐」），登记为目标缺席、期望输出为空。需要注意，34479 在这条上输出为空，是正确的，所以它在评测里是一条通过的回归项，不能代表用户看到的失败。其余 4 条没有确认是否有目标说话或参考文本，放入 `pending_labels`，不打分。

## 结论与建议

1. **链路**：case-10 的 `context canceled` 需要前端或引擎侧排查，长片段（19 秒）的流被取消；同时，第一批的 case-04 同一 segment 出现不同音频也还没有结论。
2. **短片段**：1–2 秒片段不要送模型，或者只在后面有足够语音时才送（评测集的 `abs-short` 为 75% 误输出）。
3. **注册音频**：第二批换了一段注册音频，行为仍然是对不在场声音宽松，说明问题不是某一段注册音频偶然造成的；注册音频质量检查仍然需要。
4. **数据**：5 个包里只有 1 个能确认标签。请业务方在反馈时说明每个片段里目标说话人有没有说话、说了什么；持续收音的场景尤其需要，因为注册人大多时候没说话，最适合构造目标缺席的回归集。

## 局限

- 业务包里没有逐字稿，case-08、09、11、12 的是否误输出无法判断；这里的结论只来自回放对照。
- 只有 5 条，同一位测试人员、同一个环境。
- 随机错误说话人对照只有 20 个说话人（AISHELL 测试集的说话人数）。
