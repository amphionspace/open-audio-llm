# 2026-10-30 复盘：真实会议训练数据被反复训练到背熟

**结论：Diarization 主线从 10-08 起一直没超过起点，原因是模型把真实会议训练数据背熟了，而不是之前怀疑的标签质量、输出格式或缺少辅助任务。** 这个问题本可以在 10-08 就查清；我们一直在开新的对照组，却没有先核实“疑似过拟合”这条已记下的线索。

## 证据

起点 Emilia2 6000 步，不计复读 cpER（%）。诊断记录在 Diarization 重启第一轮的 `tasks/05-train-fit/`（分支 `feat/diarization-ts-aux`）。

| 窗口 | AliMeeting | AISHELL-4 |
| --- | --- | --- |
| 最近几轮反复训过的训练窗口（抽样） | **7.5** | **6.1** |
| 10-08 起留出、不再训练的 18 场训练集会议（同一构建、同一批房间） | 23.7 | 18.4 |
| 官方 dev / test | 20.4 / 21.1 | 23.6 |

- 只有反复训过的内容错误率低。换成同房间、大部分同一批人的新内容，就回到没见过的水平。
- 同期训练 loss 每轮从约 0.215 降到约 0.188，dev 却不动，最好的点总在中段（4000–5000 步）。

## 重复了多少遍

按每轮数据预检的配额估算，每秒真实会议训练音频被听了多少遍。同一段音频的 30 / 120 / 300 / 600 秒窗口和两种声道视角都算同一份内容；分母是 v2 训练音频（AliMeeting 88.7 h，AISHELL-4 100.7 h）：

| 轮次 | 步数（到选中点） | AliMeeting | AISHELL-4 |
| --- | --- | --- | --- |
| zh-farfield-mix（10-10） | 14000 | 13.4 | 15.9 |
| zh-dialogue-mix（10-10） | 18000 | 17.2 | 20.5 |
| zh-emilia2-dialogue（10-12） | 6000 | 4.6 | 5.5 |
| **起点之前合计** | | **35.1** | **41.8** |
| 重启第一轮（10-28，每组 12000 步） | 12000 | 11.2 | 12.9 |

更早的 many-speaker-long / continue、zh-first-mix 和 10-08 之前的 LoRA 阶段，用的数据版本缺少时长统计，没有计入，所以实际遍数比表中更多。

## 为什么没早发现

1. **配比只看任务权重，不看重复遍数。** 真实会议约 190 小时，却占每轮采样的 35%。同一段音频切成 4 种窗长 × 2 种声道视角，记录数看起来多了 8 倍，文字却完全相同。数据预检只检查“每条都被覆盖”，不检查重复多少遍。
2. **监控看不到过拟合。** 训练只记总 loss，没有按来源的 loss，也没有“训过的数据 vs 没训过的数据”的对比。“loss 降、dev 不动”这个典型信号一直没被识别出来。
3. **“疑似”没有人跟进。** [10-08 归档](../2026-10-08/README.md) 已写下“8000 之后会议集变差，真实会议重复读取约 8 次，疑似过拟合”，但没有核实，也没有规则要求核实。之后每轮把重复推得更高。
4. **执行实验时用新实验代替了定位。** 重启第一轮直接开了 6 组（A–G，约 533 卡时），都假设模型“缺信息”：改标签、加时间刻度、加辅助任务，没有先花一小时做拟合诊断。这违反了守则里已有的“先定位，不得用再做更多实验代替定位”。
   - A / C / E 都在 4000–5000 步最好、之后变差，这被当成训程问题，又加开了 G 组（缩短训程），而不是去查过拟合。
   - 选模从 12 个保存点里挑 dev 最好的一个，把约 1 点的评测噪声挑成“提升”，让错误的假设又延续了几轮。
5. **没有干净的对照集。** 唯一现成的同构建留出数据（zh245 的 18 场会议）在 10-08 之前被最早的起点训过，不能算完全没见过。这次结果仍然可用，因为它在最近几轮没再训练，表现和完全没见过的数据一样。

## 已做的改动

在 [AGENTS.md](../../../AGENTS.md)「Experiment Quality」和[训练入口与复现](../../guides/training.md)里加了三条：
- 按独特内容算重复遍数；
- 能力不涨时先做拟合检查；
- 已记下的“疑似”问题，下一轮启动前必须核实。

## 下一步（待定）

下一轮方向由用户决定。可选方向：
- 把真实会议的重复压下来，去掉同文字的多份视角、降低权重；
- 补充没训过的多人真实对话；
- 如果重复降下来以后仍不动，从背熟之前的模型出发。
