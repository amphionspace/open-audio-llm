## 二、评测集升级

这一轮的重点是空白噪声导致的幻觉，原有评测集覆盖不到，所以新登记了两套评测集（数据登记见 audio-data-contract `feat/asr-babble-bench-blank-noise`）：

- **`open-audio-llm/asr-babble-bench@v4-20261104`**：在 v3 原有 16 个切分的基础上，新增 11 个参考为空的切分。
  - 鼎桥设备真实空白：三个说话人分离模型都判为"无人说话"的区间，FSMN-VAD 检出语音的片段隔离，共 364 段。
  - 合成底噪：近乎数字静音、白 / 粉 / 棕噪声底噪。
  - 50 Hz 电流嗡声。
  - FSD50K 评测划分的环境声：稳态噪声、突发声、咳嗽 / 喷嚏 / 呼吸，不含人声和音乐标签。
  - 0.3–1.5 秒的混合短片段。
  - 合成底噪、嗡声、稳态 / 突发环境声上，各版本误输出都只有 0–1 条。误输出集中在鼎桥真实空白和咳嗽呼吸两类，这两类是后续改进的重点。
- **`tdtech/badcase@v3-20261104`**：鼎桥 11-02 反馈的 `e警保` 回退，共 6 条音频，按不同热词表分成 5 个切分。
  - 表里有 `e警保` 时（只有它、加上"义警"、加上 43 个近音"警"词），各版本基本全对（cluster 5/6，唯一错的是一条合成音频）。
  - 表里只有"义警"、没有 `e警保` 时，各版本都 0/6。两个词读音相同，模型分不出来，这不算模型缺陷，所以只作观察项、不作守门。线上词表已去掉"义警"（audiollm-go main-td `e60dc4ae`）。
