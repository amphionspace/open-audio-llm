# 跨语言注册：TS-ASR 会把目标判成"不在场"（2026-11-09）

**结论：注册语言和混合段语言不同时，模型大面积漏识目标，下游 badcase 在评测集上稳定复现。** 以"两轮相加"为例，真人说话人在同一批场景中只换注册：
- 中文混合段、英文注册：整句漏识从 1–4% 升到 32–39%；
- 英文混合段、中文注册：从 4–11% 升到 18–30%。

漏掉的句子几乎都是模型输出了"目标不在场"，不是跟错了人：目标缺席时的误报不升反降。GRPO 之前的 SFT 073 avg3 问题更严重（中文混合段漏识 52–61%），所以 GRPO 没有加重这个问题，反而减轻了一部分。现有训练数据里注册与混合段始终是同一语言，这是最直接的成因假设，还没有单独验证。

## 来由

下游 badcase：注册音频里说话人说中文（"今天在上海来去测试我们的demo…"），5 分钟录音里他用英文主讲。候选包在 16 段里输出空 14 段；换成从同一段录音截取的 5 秒英文作注册后，主讲人的话基本完整转写，另一个说话人的话基本被排除。外部声纹模型（ECAPA）给出的注册—主讲人相似度为 0.35，在三个说话人里最高。

## 评测集

`ts_asr_crosslingual`（数据契约仓库 PR #173、#175），AmphionEval 评测集名为 `ts-asr-crosslingual@v1-20261109`（中文混合段）和 `ts-asr-crosslingual-en@v1-20261109`（英文混合段）：

- **成对设计**：每个场景出两份，注册分别是同一说话人同语言的另一句（same），或另一种语言的一句（cross）。两份场景相同，只换注册。下表只统计混合段音频完全相同的对，约占 98%。
- **真人（cv）**：Common Voice 里同一账号既录中文又录英文、且从未作为 TS 训练目标的 78 人。同一人中英文之间的 ECAPA 余弦平均 0.673，不同人之间 0.172。
- **合成（tts）**：50 个 Qwen3-TTS 跨语言克隆音色，注册与混合段都是合成音。同一音色中英文之间的 ECAPA 余弦平均 0.835。
- **场景**：
  - 目标在场：单人（solo）；1 个、2 个干扰人（k1、k2）。
  - 目标缺席：1 个、2 个干扰人（abs1、abs2）。
- **只测语言不同**：Common Voice 同一账号的两种语言多为同一设备录制，所以这里不包含设备差异。

## 结果（部署推理栈 vLLM 0.18.0，5 秒注册；整句漏识与误报为条数占比）

**真人，中文混合段**

| 场景 | 两轮相加 同语言：CER / 漏识 | 两轮相加 跨语言：CER / 漏识 | SFT 073 同语言 | SFT 073 跨语言 |
|---|---|---|---|---|
| 单人 | 8.5 / 1.7% | **46.5 / 31.7%** | 14.9 / 4.2% | 80.9 / 55.8% |
| 1 个干扰人 | 12.2 / 0.9% | **52.3 / 33.3%** | 15.9 / 3.4% | 75.2 / 60.7% |
| 2 个干扰人 | 19.1 / 4.3% | **60.4 / 38.8%** | 20.1 / 4.3% | 79.5 / 51.7% |
| 目标缺席：误报（1 / 2 个干扰人） | 2.5% / 1.7% | 0.0% / 0.8% | 0.8% / 1.7% | 0.0% / 0.0% |

**真人，英文混合段**

| 场景 | 两轮相加 同语言 | 两轮相加 跨语言 | SFT 073 同语言 | SFT 073 跨语言 |
|---|---|---|---|---|
| 单人 | 15.3 / 5.0% | **31.4 / 24.2%** | 17.5 / 5.8% | 41.5 / 32.5% |
| 1 个干扰人 | 14.7 / 4.2% | **29.5 / 18.3%** | 16.1 / 5.0% | 46.0 / 34.2% |
| 2 个干扰人 | 28.1 / 10.8% | **48.2 / 30.0%** | 30.7 / 10.8% | 57.8 / 40.0% |
| 目标缺席：误报 | 0.0% / 2.5% | 0.0% / 0.0% | 0.0% / 0.8% | 0.0% / 0.0% |

**合成（两轮相加）**

| 场景 | 中文混合段：同语言 → 跨语言（CER / 漏识） | 英文混合段：同语言 → 跨语言 |
|---|---|---|
| 单人 | 2.5 / 1.0% → 28.5 / 18.0% | 4.9 / 0.0% → 7.3 / 4.3% |
| 1 个干扰人 | 4.4 / 0.0% → 22.7 / 10.3% | 6.1 / 2.0% → 7.1 / 1.0% |
| 2 个干扰人 | 6.2 / 1.0% → 33.4 / 17.2% | 8.9 / 1.0% → 9.5 / 0.0% |

- 合成音色的英文混合段（中文注册）几乎不受影响。它的中英文音色一致性比真人高（0.835 对 0.673），所以这一项可能偏乐观。
- 合成音色的目标缺席误报偏高（英文同语言 11–19%），说明不同合成音色之间更难区分。这一点不代表真实情况，判断时以真人部分为准。

完整逐场景表见 `paired-results.txt`，脚本为 `xl_analyze.py`。

## 后续

- **成因待验证**：训练数据中注册与混合段从来不跨语言（在线混音、场景池、真实会议都按同一语料、同一语言配注册）。
- **可能的修复方向（待讨论）**：
  - 在训练里加入跨语言注册：真人双语数据很少（Common Voice 只有 125 人）。可以用 TTS 把训练目标的注册克隆成另一种语言，或者直接采用跨语言克隆的合成说话人。
  - 在部署端让下游用与使用场景同语言的注册音频。
- **这个集测不到的**：注册与混合段录音设备不同的影响，需要下游提供同一人在不同设备上的录音。
