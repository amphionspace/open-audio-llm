### 口语重复：各数据集写法不同，不能统一去掉

每千个参考词里相邻重复词（“the the”）的个数：

| 数据集 | 参考答案 | 底座输出 | 11.17 输出 |
| --- | --- | --- | --- |
| AMI | 13.6 | 13.7 | 13.6 |
| GigaSpeech | 7.2 | 6.5 | 6.4 |
| Earnings22 | 6.4 | 0.1 | 0.1 |
| Monsoon | 6.1 | 6.1 | 5.8 |
| URGENT24 | 5.6 | 4.3 | 5.3 |
| VoxPopuli | 2.4 | 0.3 | 1.3 |
| SPGISpeech | 0.4 | 3.3 | 5.5 |

- 只有 SPGISpeech 的参考答案是去掉重复的整理稿，11.17 在这里多出的插入主要是重复词。AMI、GigaSpeech、Earnings22 的参考答案反而保留重复。所以“把英文训练标注里的重复全部删掉”会在 AMI、GigaSpeech 上丢分，不采用。
- 我们英文训练数据里，GigaSpeech（终版文本 v1）每千词 5.8 个重复、Emilia 英文（v2）7.5 个；Common Voice 0.2、LibriSpeech 0.7、FLEURS 英文 0.1。语气词（uh、um）榜单打分时会去掉，不影响分数。
- 结论：差距主要来自缺少榜单领域的训练数据，以及各领域转写写法不同。补上各语料自己的训练集，让模型按领域学到对应写法；这也是 Musci 的做法。

## 方案

1. **SFT 增量，用同条件对照做差值。**X = v99z 的配方加上表中新数据，其余（起点 073 avg3、冻结音频编码器、代码、种子、6000 步）与 v99z 完全相同。候选 = 11.17 + (X − v99z)。v99z（attempt 132）已经训练好，只需再训 X 一次。这是[上一轮](../2026-11-24-open-asr-leaderboard/README.md#v99z-与差值合并)验证过能去掉合成漂移的做法。
2. **强化学习**：从候选出发，在榜单领域训练集上用词错率做奖励，同时保留 11.17 那一轮强化学习里目标说话人识别和热词的样本与奖励，KL 约束到候选。第 1 步不够 5.15 时再做。
3. **守门**：交付 27 套评测（`compare_delivery.py`）全部不差于 11.17，其中 v12 ≤ 12.88 / 371 / 369、英文 TS 误报 ≤ 655、中文普通识别 ≤ 4.39；榜单 7 集用本地镜像预估；另用榜单没用过的英文数据（Earnings21、LibriSpeech、Common Voice 英文测试集）核验，确认不是只在榜单集上变好。

**预先登记的判定（第 1 步）**：候选英文 7 集平均 ≤ 5.73（回到底座）且守门全过，就进入第 2 步；守门不过时先定位是哪类新数据带来的。上一轮的经验是，普通识别数据可能让英文 TS 更倾向“有声就转写”（误报 +44 条），出现时加同领域的目标缺席样本。

## 零训练检验：11.17 + α ×（Musci − 底座）

2026-11-25 用户批准参考 VOPD（arXiv 2611.30325，在线蒸馏 + 可验证奖励）试用更强的模型。能当老师的只有和我们同架构、同词表的模型：Musci-ASR（`Musci-research/Musci-ASR-qwen-1019`，Apache-2.0，Qwen3-ASR-1.7B 的 GRPO 微调，词表 151,936，revision c376e9c，sha256 已核对）。Musci 和 11.17 都从 Qwen3-ASR-1.7B 出发，所以先不训练，直接把 Musci 相对底座的改动按系数 α 加到 11.17 上（`task_vector_merge.py`，MTP 头沿用交付包）。

Musci 的改动很小：语言模型部分 |Musci − 底座| = 1.19，只有 |11.17 − 底座| = 233.8 的 0.5%；音频编码器也有少量改动（0.51 对 79.2）。

### 第 2 步改用在线蒸馏的实现要点（11-25 核查）

- GRPO 用的 ms-swift 4.5.3 已支持 `--teacher_model`（OPD-RL）：学生采样后，老师对采到的每个词元算对数概率，作为逐词优势与奖励优势相加。它只取采样词元，不是 VOPD 的前 16 个候选；VOPD 的“按验证信号与老师一致程度放大”可以写成逐词优势里的一项 λ·c·(log p_老师 − log p_参考)。
- 要补的两处：老师信号只能加在普通英文识别样本上（Musci 不会目标说话人和热词，混合批次里其余样本的老师项要置零）；Musci 没有 11.17 的 `audio_tower.sep_token`，以 11.17 的模型类型加载老师时要处理这个缺项。
