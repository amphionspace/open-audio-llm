# 目标说话人评测集（Benchmark）计划

状态：2026-10-13。依据：[基线与追加发现](README.md)、[业务 bad case 第一批](../2026-10-12-ts-badcase/README.md)、[第二批](../2026-10-13-ts-badcase-batch2/README.md)。

目标：评测集要能**预测真实业务里的失败**，并作为训练的验收门。判断标准是：业务里出现的每一类失败，评测集里都有对应场景，并且数值变化方向一致。

## 这轮证据改变了什么

1. **v1 低估了失败。** 发言间隙是数字静音，真实录音总有噪声底；加一层几乎听不见的噪声底，目标缺席误输出率从 6–15% 升到 14–27%（−60 dBFS）直至 42–51%（−40 dBFS），并出现解码循环。→ v2 给每个场景加噪声底。
2. **同一个人的两段注册录音，一个拒绝歌声、一个接受。** 结果对具体的注册录音很敏感，而随机错误说话人的接受率只有 4%。→ v2 增加「真实注册」场景：用业务反馈里的两段真实注册录音，配上大量没有他的说话人，给出有统计意义的误输出率。
3. **外部说话人验证门只在单人片段上可行。** 目标单独说话 vs 缺席 AUC 0.97；多人混合时 0.45–0.80。→ 验证门可以作为前端对「单人片段」的补充，不能代替 TS 模型；评测集已有的场景可直接评估它。
4. **非人声上的幻觉是微调引入的。** 底座几乎不在噪声、静音、极短片段上输出文字，34479 输出 50–75%。→ 训练数据需要「非人声输入，输出为空」的样本，这是有因果证据的修复项。
5. **第二批业务包里只有一条能确认标签。** 评测集的价值取决于业务提供的标签，业务批次要继续累积（评测集已是累计登记）。

## 评测集的现实性原则（2026-10-13 补充）

评测条件要基于业务现实：手机原始麦克风、10–50 cm、办公室和户外，不做极端测试。削波、电话 μ 律编码、3.4 kHz 窄带、0 dB 的注册污染、几种不利因素同时出现的组合压力等不贴近业务的条件保留在评测集里作诊断，**不计入分组平均和脆弱点排序**（AmphionEval 的表里列在「其他」）。贴近业务的条件：真实环境噪声、真实与模拟房间响应、整体电平（业务实际在 −46 到 −16 dBFS）、注册音频的短、污染、开头静音。

## v2（已构建、已评测 34479）

`ts_asr_benchmark@v2-20261013`：64 个场景、8,380 条。

- 所有场景加噪声底：白噪声或粉红噪声，−65 到 −35 dBFS 均匀抽取，注册音频和混合音频各自独立抽取。噪声底在场景之后抽取，所以 **v2 的前 60 个场景与 v1 逐条相同**，同名场景可以和 v1 做配对比较，直接量化噪声底的影响（630 条抽查全部相同）。
- 新增 `realreg` 组（4 个场景）：业务反馈里测试人员的两段注册录音，配 1–2 个没有他的说话人（各 200 条）和纯音乐（各 120 条）。
- 评测集 `open-audio-llm/ts-asr-benchmark@v2-20261013`。v1 继续保留，作为连续性对照。
- 34479 的 v2 基线：与 v1 同一批样本的配对差值显示 60 个场景中 39 个显著变差，缺席误输出平均 +8 个百分点；真实注册录音下纯音乐误输出 80–91%、缺席 26–39%（详见 [README](README.md)）。

## v3 与真实对话（本轮新增）

- **v3**（`ts_asr_benchmark@v3-20261013`，110 个场景、13,900 条）：v2 的基础上把底噪换成真实录音（WHAM!、DNS5 AudioSet 与 Freesound，只取电平稳定的片段），房间响应加入实测 SLR28，新增「脆弱性面板」（底噪类型与强度、房间响应、电平，全部与同一批基础场景配对）。前 60 个场景仍与 v1 逐条相同。
- **真实对话窗口**（`ts_asr_real@v2-20261013`，1,134 条）：AliMeeting 远场、AISHELL-4 远场、MagicData-RAMC 手机通话的人工标注测试集，加上 Emilia2 网络爬取的对话（MOSS 伪标签），不做任何混合；同一窗口一条在场、一条缺席。34479 在这些同域或可能见过的数据上缺席误输出仅 0–16%（手机通话单人缺席 24%，其中 20% 复读），说明合成评测集的苛刻来自训练没见过的说话人、录音条件和底噪。Emilia2 用到的 260 个录音已列入排除清单，训练必须排除。
- 结果见 [README](README.md)。主要修正：**合成白噪声比同电平的真实环境噪声更伤模型**，此前用白噪声的结论夸大了；真实环境噪声从信噪比 15 dB 起才明显变差；混响让模型漏转写，输入太轻（−45 dBFS）漏转写超过四分之一。

## 评测集如何用作训练验收门

训练验收的具体门限见[修复方案](../2026-10-12-ts-badcase/training-plan.md)；在 v2 上要对比的是：

- 配对差值：v2 减 v1 的噪声底影响本身是训练要缩小的量（噪声底增强是训练数据里的优先项）；
- 每个场景用两次运行的噪声（约 2 个百分点）作为最小有意义差异；
- 保持项：干净单人、棚内录音、持续对话 · 1 个干扰人不变差；
- 报告复读条数，不只报 CER。
