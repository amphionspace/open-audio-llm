# 目标说话人 ASR 评测集与 checkpoint-34479 基线

**结论：新评测集把业务反馈的三类问题都量化出来了，而且每一类都能对应到具体的场景因素。** 已发布的 checkpoint-34479 在注册音频被污染或太短、有声音相近的干扰人、目标只说一两个字、干扰人多、没有说话声时都明显失效；干净、单人、棚内录音的场景基本正常。

评测集 `ts_asr_benchmark@v1-20261013`（audio-data-contract）：7,740 条、60 个场景、约 25 小时。AmphionEval 评测集 `open-audio-llm/ts-asr-benchmark@20261013`。设计与规则见 audio-data-contract `docs/datasets/ts-benchmark.md`。对象：发布包 `AmphionASR-1.7B/releases/20260926/amphionasr-1.7b-v3-ckpt34479`，vLLM 0.18.0、`serve.sh tsasr`、bf16、贪心、`max_new_tokens=512`。没有请求失败。

> **2026-10-13 追加**：v1 评测集的发言间隙是数字静音（精确的 0），而真实录音总有噪声底。[追加发现](#追加发现2026-10-13-晚)表明，给 v1 的音频加一层几乎听不见的噪声底，目标缺席的误输出率就翻倍甚至更高，所以 **v1 低估了真实场景的失败**。v2 已按此修正，见 [Benchmark 计划](plan.md)。

| 组 | 场景 | 回答的问题 |

## 注册音频劣化（配对差值，百分点，95% 区间）

相对干净注册，同一批场景。目标在场看 ΔCER，目标缺席看 Δ误输出率。干净注册基线：CER 19.1、误输出率 14.7%。

| 注册条件 | 目标在场 ΔCER | 目标缺席 Δ误输出 |
| --- | --- | --- |
| 仅 1 秒语音 | +11.1 [+5.3, +17.6] | **+43.3** [+34.7, +51.3] |
| 被他人声音污染 0 dB（压力） | **+36.2** [+28.5, +44.5] | **+37.3** [+28.7, +45.3] |
| 被他人声音污染 10 dB | +16.9 [+11.0, +23.8] | +25.3 [+18.0, +33.3] |
| 开头 1.5 秒静音 | +3.2 [−1.2, +8.7]（不显著） | +23.3 [+16.7, +30.0] |
| 10 dB 噪声（MUSAN） | +1.2 [−1.6, +4.0]（不显著） | +9.3 [+4.0, +14.7] |
| 混响 | +7.0 [+2.0, +12.0] | +7.3 [+1.3, +13.3] |
| 4 kHz 低通 | +4.5 [+0.5, +9.0] | +1.3 [−3.3, +5.3]（不显著） |
| 低电平（对照） | −2.5 [−6.7, +1.1]（不显著） | −7.3 [−12.0, −3.3] |

- 注册语音太少和被他人污染最伤，同时损伤转写和拒识。开头静音只增加误输出，不伤转写；窄带只伤转写，不伤拒识。
- 电平不重要：低电平注册没有变差，误输出还略低。这与此前的分析一致（训练与测试注册电平本来就接近）。
- 这里 MUSAN 噪声注册对 CER 没有显著影响，而此前对 AISHELLMix 用白噪声 10 dB 做的探测影响很大（3mix ΔCER +15.7）；说明模型对白噪声比对真实噪声更敏感，或者与基础场景难度不同，没有单独拆开。

## 进场、离场与缺席

| 场景 | CER | 漏识 | 转写了别人 |
| --- | ---: | ---: | ---: |
| 目标单独说话（对照） | 6.0 | 0.0 | — |
| 持续对话 · 1 个干扰人 / 4 个干扰人 | 12.9 / 46.2 | 1.7 / 10.8 | 2.5 / 12.1 |
| 目标插话 · 1 / 2 / 4 个干扰人 | 7.9 / 26.0 / **80.0** | 1.7 / 11.7 / 23.3 | 1.7 / 6.6 / 32.6 |
| 中途进场 / 离场 · 2 个干扰人 | 22.7 / 22.5 | 5.0 / 5.0 | 6.1 / 5.3 |
| 轮流对话 · 2 / 4 个干扰人 | 19.2 / 41.0 | 2.5 / 2.5 | 6.8 / 16.2 |
| 被抢话 · 1 / 3 个干扰人 | 14.4 / 59.4 | 4.2 / 23.3 | 3.5 / 19.6 |
| 只说一两个字 · 1 / 3 个干扰人 | 61.5 / **113.3** | 11.7 / **55.0** | 16.0 / 38.9 |
| 目标比干扰人轻 6–12 dB | 40.5 | 11.7 | 13.2 |

- 干扰人数是最强的因素：在场样本按干扰人数 0 / 1 / 2 / 3 / 4 的 CER 为 8.4 / 18.0 / 29.1 / 72.6 / 53.5，漏识最高 39%。3 个干扰人的样本里包含被抢话和只说一两个字两个难场景，所以它高于 4 个干扰人。
- 目标只说一两个字时，3 个干扰人下超过一半被漏掉，CER 超过 100%（插入错误），这正是「别人一直说，目标只插一两句」的场景。
- 重叠越多越差：目标语句时间内重叠比例 ≥ 0.6 的 CER 28.7，< 0.2 的 15.5；但低重叠时「转写了别人」反而更高（11.5%，对比 0.2–0.6 的 1.7%），可能是别人的话不重叠时更容易被当成目标，这是推测，没有单独验证。
- 轮流对话几乎不重叠，4 个干扰人仍有 16.2% 转写了别人。

## 目标缺席与没有说话声

| 场景 | 误输出率 [95% 区间] | 说明 |
| --- | ---: | --- |
| 缺席 · 2 个干扰人 | 6.7 [3.4, 12.6] | 最乐观的缺席场景 |
| 缺席 · 1 个干扰人 | 15.8 [10.4, 23.4] | 单个干扰人比两个更容易被接受 |
| 缺席 · 4 个干扰人 | 16.7 [11.1, 24.3] | |
| 缺席 · 长片段（22–26.5 秒） | 7.5 | 复读 7.5% |
| 缺席 · 声音相近的注册人 | **41.7** [33.2, 50.6] | 与同组 `abs-k2` 配对：**+35.0 [+25.8, +45.0]** |
| 缺席 · 极短片段（0.4–1.2 秒） | **75.0** [66.6, 81.9] | 输出多为「你」「我」「是」等幻觉，只有 4% 像干扰人的话 |
| 纯噪声 | 53.3 [44.4, 62.0] | |
| 纯音乐 | 50.0 [41.2, 58.8] | |
| 道路交通 | 55.0 [46.1, 63.6] | |
| 近乎静音（−60～−45 dBFS） | **75.0** [66.6, 81.9] | 输出短词和整句，如「我感觉我应该去」 |
| 极短噪声 / 长噪声 | 60.8 / 66.7 | 长噪声复读 13.3% |

- 目标缺席时有干扰人说话，误输出基本都是在转写干扰人的话（除极短片段外，缺席场景中 50–100% 的误输出像干扰人的内容）；声音相近的人会让误输出率翻 6 倍。
- 没有说话声时 50–75% 输出文字。第一次运行的抽查里，只有 5–7% 的输出像注册音频的内容，所以不是复述注册，而是模型自己的幻觉。这类输入在实际使用里会出现，因为 VAD 切出的片段常常没有目标。

相对无背景的配对对照（在场 CER 19.2，缺席误输出 10.0%）：

| 背景 | 目标在场 ΔCER | 目标缺席 Δ误输出 |
| --- | --- | --- |
| 混响加噪声 | +16.4 [+10.4, +23.8] | +1.7 [−2.5, +6.7]（不显著） |
| 道路交通 | +12.7 [+7.6, +18.3] | +7.5 [+0.8, +15.0] |
| 背景音乐 | +6.0 [+2.8, +9.6] | +3.3 [−3.3, +9.2]（不显著） |

目标单独说话（对照）：加背景音乐 CER 8.6，加道路交通 10.6。录音来源影响很大：棚内录音（AISHELL-3）在场 CER 3.5、缺席误输出 6.7%，手机录音池（KeSpeech、MagicData、AISHELL-2）在场 CER 26.5、缺席误输出 41.7%。手机池含方言口音，所以 CER 里混有口音本身的难度；缺席误输出这一项差距更能说明问题。

## 用这个基线怎么判断训练是否有效

按此前的修复方案，验收时对比同一个评测集：

- 注册音频劣化：仅 1 秒、被污染、开头静音下的缺席误输出（基线 +43 / +25 / +23）。
- 声音相近的缺席（41.7%）和单个干扰人缺席（15.8%）。
- 没有说话声和极短片段（50–75%）。
- 目标只说一两个字、干扰人多（漏识 55%、CER > 100%）。
- 保持项：干净单人、棚内录音、持续对话 · 1 个干扰人不变差。


## 追加发现（2026-10-13 晚）

### 已发布的基线运行与运行间噪声

34479 的基线已按标准流程（`ae open-audio-llm after-training`）运行并发布：运行 `run-20261013T093517Z-973c7714`，W&B `1016097967-amphion/open-audio-llm`，COS 记录已发布，AmphionEval 的 `ae results export --task asr --tag target-speaker` 会给出 CER、漏识率和误输出率三张表。第二次独立运行（同数据、同模型、不同批大小）与第一次相比：

- 94.5% 的样本输出归一化后完全相同；
- 各场景误输出率的差异：平均 0.4、最大 1.7 个百分点；CER 差异：平均 0.5、最大 1.9 个百分点。

所以**场景间或两次评测间小于 2 个百分点的差异按噪声处理**。

### 噪声底：v1 低估了失败

此前的回放里，业务包都是真实录音，必然带噪声底，而评测集是合成的数字静音。对 v1 的 11 个场景各取 100 条，给注册音频和混合音频各加一层白噪声底（−60、−50、−40 dBFS；说话约 −25 dBFS，所以信噪比约 35、25、15 dB，几乎听不见），配对对比：

| 场景（n=100） | 无噪声底 | −60 dBFS | −50 dBFS | −40 dBFS |
| --- | ---: | ---: | ---: | ---: |
| 缺席 · 干净注册，误输出率 % | 13 | 22 | 32 | **50** |
| 缺席 · 1 个干扰人，误输出率 % | 15 | 27 | 36 | **51** |
| 缺席 · 2 个干扰人，误输出率 % | 6 | 14 | 23 | **42** |
| 纯噪声，误输出率 % | 53 | 52 | 56 | 69 |
| 极短片段（0.4–1.2 秒），误输出率 % | 76 | 68 | 68 | 74 |
| 目标单独说话，CER %（去掉复读） | 6.1（5.7） | 5.6（5.6） | 33.2（6.6） | 34.9（8.3） |
| 持续对话 · 1 个干扰人，CER % | 13.0 | 14.3 | 17.6 | 26.3 |
| 目标插话 · 2 个干扰人，CER %（复读条数） | 26.1（0） | 63.2（1） | 87.9（2） | **290.4（9）** |
| 棚内录音，CER % | 3.5 | 11.0 | 12.5 | 43.9 |

- 误输出率随噪声底单调上升，−60 dBFS（几乎无声）就明显变差。
- 复读（解码循环）随噪声底增多，单个循环样本就能把整个场景的 CER 拉到 30% 以上，所以报告里把复读单独列出。
- 这与业务包一致：真实录音里反复出现「我我我」「你你你」和对不在场声音的接受。
- 局限：噪声底用的是白噪声，没有拆开真实房间噪声的差异；n=100，复读的条数很少。

### 说话人验证门：只在单人片段上可行

对每条记录计算 3 秒注册与整段混合音频的 WeSpeaker ECAPA 余弦，看「目标在场」与「目标缺席」能否分开（AUC，1.0 完美，0.5 随机）：

| 对比 | AUC | 等错误率 |
| --- | ---: | ---: |
| 目标单独说话 vs 缺席 · 1 个干扰人 | **0.97** | 7.5% |
| 持续对话 · 1 个干扰人 vs 缺席 · 1 个干扰人 | 0.80 | 26.7% |
| 手机录音：在场 vs 缺席 | 0.82 | 24.2% |
| 注册仅 1 秒语音 | 0.71 | 33.3% |
| 目标插话 · 2 个干扰人 vs 缺席 | 0.61 | 40.0% |
| 目标只说一两个字 · 1 个干扰人 | 0.61 | 44.2% |
| 声音相近的缺席 | 0.56 | 45.0% |
| 目标插话 · 4 个干扰人 | 0.45 | 54.2% |

- 单人片段（只有目标或只有别人）上外部验证门很好用，这正是业务里 pad 声音与本人声音的情形；一旦片段里是多人混合，验证门基本失效，不能替代 TS 模型。
- 方法上的陷阱：不加噪声底时，这个对比在目标单独说话时得到的相似度异常低（AUC 0.60，对比 0.97），因为发言间隙的数字静音扭曲了嵌入；所以任何拿这个评测集做的后处理分析都需要噪声底。原始输出见 `results/gate-analysis-*.txt`。

### 底座模型对照：非人声上的幻觉是微调引入的

用官方 vLLM 方式评测底座 Qwen3-ASR-1.7B（普通 ASR，只送混合音频，没有注册），与 34479 在同样的非人声场景（每个场景前 120 条）对比，输出文字的比例：

| 场景 | 底座 | 34479 |
| --- | ---: | ---: |
| 纯噪声 | 0.0% | 53.3% |
| 近乎静音 | 0.0% | 75.0% |
| 极短噪声（0.3–1 秒） | 0.0% | 60.8% |
| 长噪声（22–26.5 秒） | 0.0% | 66.7% |
| 纯音乐 | 20.8% | 50.0% |
| 道路交通 | 21.7% | 55.0% |
| 目标单独说话，CER | 3.8% | 6.0%（带注册） |

底座在噪声、静音、极短片段上基本不输出文字；34479 在这些输入上输出 50–75%。所以**非人声上的幻觉是微调引入的，不是底座本来就有**，原因很可能是训练数据里没有「非人声输入，输出为空」的样本（TS 数据里的负样本是「别人在说话、目标缺席」）。训练数据里需要加入噪声、音乐、静音和极短片段、目标为空。

### v2 基线（加噪声底、新增真实注册录音）

`ts_asr_benchmark@v2-20261013`，64 个场景、8,380 条，同一个 34479、同样的服务。v2 的前 60 个场景与 v1 逐条相同，所以下面是同一批样本的配对差值（v2 减 v1）：

- 60 个场景里 39 个显著变差（区间不含 0）。
- 目标缺席和没有说话声的 27 个场景：误输出率平均 +8.0、中位数 +7.5 个百分点（去掉 `enroll-quiet` 平均 +6.4）；在场的 33 个场景 CER 平均 +10.3、中位数 +6.9。
- 变化最大的：`enroll-quiet`（注册降 25 dB，加噪声底后注册的信噪比可能为负）缺席误输出 +49.3、CER +32.3；目标插话和进场、4 个干扰人的 CER 增加 +20 到 +30。
- 干净缺席（`enroll-clean-neg`）的误输出从 14.7% 升到 25.3%（+10.7）。

真实注册录音（`realreg` 组）：业务反馈里测试人员的两段真实注册录音，配上没有他的说话人：

| 场景 | 误输出率 [95% 区间] | n |
| --- | ---: | ---: |
| 真实注册 1 · 缺席（1–2 个别人说话） | **39.0** [32.5, 45.9] | 200 |
| 真实注册 2 · 缺席 | 26.0 [20.4, 32.5] | 200 |
| 真实注册 1 · 纯音乐 | **90.8** [84.3, 94.8] | 120 |
| 真实注册 2 · 纯音乐 | **80.0** [72.0, 86.2] | 120 |
| 对照：随机 AISHELL / KeSpeech 注册 · 缺席（`enroll-clean-neg`） | 25.3 [19.0, 32.8] | 150 |
| 对照：随机注册 · 纯音乐（`nonspeech-music`） | 57.5 [48.6, 66.0] | 120 |

两段真实注册录音下纯音乐的误输出率比随机注册高 22–33 个百分点；缺席误输出也更高（第一段 +14）。这与业务观察一致：这位测试人员的注册会接受不属于他的声音，并且对不同的注册录音差别很大（两段差 13 个百分点）。完整输出见 `results/checkpoint-34479-v2-analysis.md`。

## 局限

- 合成数据，语音是朗读语料；真实对话的韵律、抢话、情绪没有覆盖。绝对数值不能直接当作线上表现，趋势和相对差更可靠。v1 没有噪声底，会低估误输出（见追加发现），v2 已修正。
- 每个场景 120–150 条，单个场景的差异要看区间。
- 说话人池只有 279 位合格说话人（studio 108、phone 151、read 20）。手机池的 CER 含口音难度。
- 噪声、音乐和交通来自 MUSAN 与 AudioSet，房间响应来自 DNS5 的模拟响应，不是真实手机麦克风录音。
- 「转写了别人」按输出与哪方文本更接近判断，是近似指标。
