## 结论

1. **0926 版（34479）相对 0923 版（33407）在目标缺席时更爱输出。** 71 个「目标缺席」和「没有人」场景里，34479 的误输出平均高 8 个百分点，44 个场景显著更高，只有 4 个显著更低（合成评测集 v3、远场补充集、噪声补充集的配对比较，`results/full/cmp-3447933407--*.json`）。字错率没有变化（加权差 −0.4）。真实同域窗口（AliMeeting 等）两者一样，所以这个退化在训练见过的域里看不出来，只在合成评测集上出现。最大的几项：注册只有 1 秒、注册低电平、真实注册录音（+25 到 +27）。
2. **两个自家版本在非人声输入上都会乱输出**（没有说话声 64% / 63%，只有人群或环境事件声 52%–56%），Cocktail 只有 7%–12%。
3. **Cocktail 几乎不拒绝**：目标缺席时误输出 75%–100%，但字错率在多数合成场景与自家模型相当，漏识很少。
4. 远场与房间响应的结果和真实校准见 [far-field-calibration.md](../far-field-calibration.md)。
