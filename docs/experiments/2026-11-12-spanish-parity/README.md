# 西班牙语对齐：评测集、v69–v78 训练与热词误出修复（2026-11-12）

**结论**

- **评测集已补齐**：西语现在有普通 ASR、嘈杂人声、热词 ASR、TS-ASR（含补充场景）、TS 热词、跨语言注册六类评测，与中英对齐。
- **普通识别已恢复**：11-06 交付的"两轮相加"在西语上基本失效，CV es 词错率 86.6%（会把西语判成英文）。v77 降到 CV / FLEURS / MLS 5.48 / 4.27 / 5.98，接近 Qwen3-ASR-1.7B 原版的 4.56 / 3.05 / 4.65。
- **热词还差一截**：
  - 列表里有正确词时，v77 好于 Qwen 原版：热词词错率 5.45 对 7.77。
  - 列表里只有近音词、没有正确词时，v77 每 100 条误出 23.2，Qwen 原版是 9.8。这是我们训练引入的回归，根因已定位，v74→v76→v77→v78 从 54 降到 33、23、19；合并后的 es091 是 12.2。
- **西语 TS 误报偏高**：v77 西语 TS 误报 293/6480，合并模型 es081 只有 150。在线混音拉低了西语漏识，但同时把误报带到了英文水平。
- **推荐候选改为 es091**：es091 = 两轮相加 + (v78 − SFT076)，不训练，只做权重相加。
  - 西语普通识别 5.41 / 4.32 / 5.71，与 v78 相当。
  - 热词列表无正确词时误出降到每 100 条 12.2，接近 Qwen 原版的 9.8。
  - 西语跨语言注册最好：词错率 27.74，漏识 30。
  - 中英保住了两轮相加的水平：中文 TS-ASR 测试集上 es091 是 12.46 / 476 / 307，两轮相加是 12.46 / 453 / 324。
  - 仍有差距：
    - 西语 TS 误报 336，es081 是 150；
    - first-other v3 漏识 100，两轮相加是 75；
    - 英文跨语言注册词错率 18.77，两轮相加是 16.48；
    - customer-ts 漏了 1 条，共 5 条。
- **es081**：两轮相加 + (v69 − SFT076)。西语 TS 误报仍是最低，但西语普通识别和热词误出落后于 es091。
- **v77 / v78**：西语普通识别和热词好，但它们从 SFT 073 继续训练，中英比两轮相加回退约 1.2 个点（中文 TS-ASR 测试集 13.6–13.7 对 12.46）。

## 西语热词误出：根因和修复

- **现象**：只给近音词、不给正确词时，模型会把本来认对的词改成列表里的近音词，例如 Fairfield→Fairchild、Marla→Mara、Ensor→Enzo。v77 剩下的误出几乎都属于这一类。
- **根因**：
  - v74 之前，训练配置里的西语 CV / MLS 都是 `task: asr`，西语从来没带过热词列表，热词能力全靠中英迁移；
  - 全局没有近音负例；
  - `hotword_miss_prob` 为 0，也就是训练里正确词总在列表中。
- **修复**：
  - **adc #201**：西语普通 ASR 记录加上读音键近音词（`metadata.confusable_hotwords`）。剔除拼写变体，并保证与评测集的正确词零重叠。
  - **v76**：引入这份数据，同时设 `hotword_miss_prob` 0.15。误出从 54 降到 33。但近音词出现概率 0.5 × 正确词缺席概率 0.15，只有约 7.5% 的列表是"有近音词、没有正确词"。
  - **open-audio-llm #144**：新增 `hotword_confusable_miss_prob`。只在普通 ASR 列表放进了近音词时生效，改用这个缺席概率；TS 列表不受影响。v77 设为 0.5，误出降到 23，同时西语 TS 误报从 347 降到 293。
  - **v78**：近音热词数据权重 1.0→3.0，误出降到 19.3。合并到两轮相加上（es091）后降到 12.2。

## 未解决

- **热词误出仍略高**：西语列表无正确词时的误出，es091 是 12.2，Qwen 原版是 9.8。v79（`hotword_confusable_miss_prob` 0.5→0.8）正在训练。
- **first-other v3 漏识上升**：从 v74 的 63 升到 v76 的 119，集中在多人（crowded）子集。v77 没有动 TS 路径，漏识仍是 120，说明不是 `hotword_confusable_miss_prob` 造成的。v78 回到 77，es091 是 100（两轮相加 75）。目前怀疑与 v76 起 `hotword_miss_prob` 0.15 也作用于 TS 热词列表有关，尚未定位。
- **西语 TS 误报高于 es081**：es091 是 336，es081 是 150。在线混音里目标在场的样本远多于缺席的。改缺席比例（v72、v73）只部分有效，这条线已经停了。
- **中英相对两轮相加回退**：v69–v78 都是从 SFT 073 继续训练，直接用会回退。es091 已经把 v78 的增量合并到两轮相加上，中文 TS-ASR 测试集持平；英文跨语言注册还差 2.3 个点。
- **西语还缺的数据**：真实会议和对话轮流、远处人声的空目标、跨语言 TTS 注册。另外，amphion-eval 的标签表里还没有 `es`。
