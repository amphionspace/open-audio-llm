# 热词评测集 v3：按热词类型和领域分项（2026-10-20）

**结论：**

- **v3 = v2 + 两种标签。** 每个正确词有类型，ContextASR 每句有领域大类，评测器按类型、按领域分开输出召回和误触发。数据 `hotword_bench@v3-20261020`，评测集 `open-audio-llm/hotword-bench@v3-20261020`。记录、音频和列表与 v2 逐条相同，总指标可以直接和 v2 比。
- **人名最难，两个模型、每个中文切片都是。** `pool50` 召回：
  - 中文合计，34479 人名 66.3%，其他各类 78–84%；Qwen3-ASR-1.7B 人名 76.6%，其他各类 89–96%。
  - 同一切片内也是人名最低，例如真实口语 72.7% / 83.8%，其他各类 86–89% / 92–93%。
  - 说了人名、列表里却没有时（`pool50_no_gold`），误触发率也最高：34479 是同切片其他类的 1.1–2.6 倍，Qwen 是 1.4–3.0 倍（AISHELL-2 上人名与地名持平）。
- **34479 给列表后，人名召回反而下降，Qwen 不会。**
  - 中文除 ContextASR 外合计：34479 人名 76.9% → 71.6%，Qwen 73.9% → 79.0%。
  - 不给列表能写对、给了 `pool50` 反而写错的人名，34479 占 25.0%，其他类 12–18%；Qwen 占 10.3%，其他类 2–4%。
  - 这些句子里 85–97% 写出了本句正确词的复核易混词（如 刘燕 → 柳岩）。读音相同的人名最多，所以人名受害最重。
- **领域之间差别比类型小。** ContextASR 13 个领域，`pool50` 召回的跨度：Qwen 86.8–94.6%，34479 76.8–82.6%，只有 6–8 个点；人名比同切片的其他类低 8–26 个点。
  - 医疗占 ContextASR 的 38%，但对总召回影响只有约 1 个点：`pool50` 召回按句合并与按领域等权平均相比，34479 为 78.7% 对 79.7%，Qwen 为 92.8% 对 91.8%。
  - 34479 在医疗上给列表后降得最多：召回 82.8% → 77.5%，B-CER 8.0%，其他领域 4.4–6.4%。
- **建议：**
  - 默认评测集改用 v3：成本不变，主指标不变，另看人名的 `pool50` 召回和 `pool50_no_gold` 误触发率。
  - 不需要为了领域均匀重造数据。
  - 34479 的短板集中在同音人名，问题在训练侧：训练时的热词列表应该带同音、近音的人名干扰词。这不在本次范围内。

## 为什么做

v2 只报每个切片的总召回和总误触发率。近一年的热词与上下文 ASR 评测里，按类别报结果的有这几篇：

- Qwen-Audio-3.0-ASR 技术报告（arXiv 2609.07549）把热词分成人名、学科术语、流行热词、AI 实体、品牌名、产品实体，各类召回差别很大：不给热词时人名最低（三个系统 32–62%），给热词后品牌名在 Doubao-ASR 上只有 57.9%。
- Contextual Earnings-22（arXiv 2604.07354）只收人名、公司名、产品名三类，按整通电话的词表给干扰词，思路和我们的租户热词池相同。
- ProfASR-Bench（arXiv 2512.23686）分金融、医疗、法律、技术四个领域报 WER，实体标了类型。

总召回会把难的人名和容易的术语混在一起。v3 给每个正确词标类型，给 ContextASR 的句子标领域大类，评测器按类型和领域分项输出。

## 怎么做的

记录、音频、正确词和全部列表与 v2 逐条相同，只加了两种标签。

**热词类型**（`metadata.hotword_types`，正确词 → 类型）：

| 标识 | 含义 |
| --- | --- |
| `person` | 人名：真实或虚构人物、角色、外文译名、带称谓的人名 |
| `place` | 地名：国家、行政区、街道、山川、建筑、景点、车站、场馆 |
| `organization` | 机构与品牌：公司、品牌、商店、政府部门、学校、医院、团体、球队、媒体 |
| `product` | 产品：产品型号、软件或 App、车型、药品商品名、设备、技术平台 |
| `work` | 作品：书、影视、游戏、歌曲、节目、文章、法规文件的标题 |
| `term` | 术语：各领域专业概念、疾病、药物通用名、物种、化学物质 |
| `other` | 其他专名：事件、会议、赛事、节日、朝代、奖项、口号、流行语 |
| `common` | 普通词：不是专名也不是术语的日常词或低频普通词 |

**ContextASR 领域大类**（`labels.domain_group`）：ContextASR 自带的 `labels.domain` 是生成文本时 LLM 写的自由文本，有 3,957 种，没法直接分项。v3 把它们归到 13 个大类：`medical`、`science_tech`、`business_finance`、`law_politics`、`military`、`sports`、`entertainment`、`culture_history`、`education`、`nature_environment`、`travel_life`、`industry_energy`、`other`。

**标注方式**：

- 类型按这个词在本句里的意思判断，同一个词在不同句子里可以不同。标注时给模型看正确词前后各 40 个字（英文 120 个字符）。
- doubao-seed-2-0-lite 标注，deepseek-v4-pro 看着标注再判一次，以复核结果为准。
- 140,901 个（句子, 正确词）中，复核没改动的占 98.5%，改了 2,140 个，多是 `common` 改成 `term` / `product` / `other`。复核模型拒答、沿用标注的 66 个；两个模型都拒答、没有类型的 5 个，评测器只对有类型的词分项。
- 3,957 个领域名，复核改了 29 个。
- 全量核查：64,413 条记录去掉新标签、换回版本号后与 v2 逐字段相同，音频索引和热词池文件逐字节相同。

## 评测器怎么分项

- `breakdowns.<来源>/<条件>.hotword_type.<类型>`：
  - `recall`：这一类正确词的召回；
  - `false_alarm_rate`：含这一类正确词的句子里，至少写出一个列表中未说出的词的比例。一句话有两类词时两类都算。`pool50_no_gold` 下就是"说了这一类词、列表里却没有它"时的误触发率。
- `breakdowns.<来源>/<条件>.domain_group.<大类>`：和其他句级标签一样，给 CER、B-CER、召回、精确率、误触发率。

## 局限

- 类型和领域大类都是 LLM 标签，没有人工核对。
- 一个正确词只有一个类型。作品名里含人名这类嵌套情况，按整体归类。
- 句级误触发按类型分项时，多类型的句子会重复计入；ContextASR 平均每句约 6 个正确词，这一项只能粗看。
- "写出易混词"按句统计：句子里写出了本句任一正确词的易混词就算，不逐词对应。
