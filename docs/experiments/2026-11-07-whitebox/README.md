# AmphionASR 白盒分析与免训练合并（2026-11-07）

**结论：不训练、把 GRPO 第十五、十六轮的更新各取全量加回 SFT 073 avg3（"两轮相加"），是目前最好的模型；按现有配方继续 GRPO 只是在挪"出不出字"的门槛。** 白盒分析还发现，模型在 LLM 第 12 层已经能分辨目标说话人在不在场，但最终仍会出字；推理时补救（探针门控、steering、加强对注册段的注意力）都没有带来稳定收益，问题在上游表示，不在决策时读不读注册段。

对象：新提示词线（SFT 073 avg3 → GRPO v15 → v16，均带联合 MTP）。评测走部署推理栈（vLLM 0.18.0，bf16，5 秒注册），口径同 2026-11-06。分析方法依据 Glazer et al. 2508.15882、Aparin et al. 2606.07473、Lin et al. 2510.12851、Mukherjee et al. 2507.17107、2606.18521。

## 一、权重更新（task 01）

GRPO 一轮约改动 16% 的 bf16 参数（音频编码器 27%、LLM 20%；embedding、lm_head、norm 基本不动），相对改动约 6e-4，是 SFT 的 1/15；LLM 第 13–16 层改得最多。第十五、十六轮更新的余弦只有 0.10–0.18（近似正交），与 SFT 更新约 0.002；更新不是低秩的（抽查矩阵 90% 能量需要约一半的秩）。推论：50% 插值把两轮各自学到的东西都砍了一半。

## 三、内部状态（tasks 03–05、08）

抽取工具 `runs/whitebox-20261107/scripts/extract_states.py`：按训练模板构造与部署一致的输入，在决定输出 ` None` 还是语言 token 的位置读 LLM 各层残差、音频编码器各层状态、注意力分布和 logit lens；v12 全量 26,750 条首 token 与 vLLM 一致 99.88%。音频编码器必须用全局注意力（FA2 会按 800 帧开窗，与训练和服务都不同）；上游 qwen_asr 的 `output_attentions` 恒为空，需用 hook 取。

- **模型"知道"但仍出字**：线性探针判断目标是否在场，在 LLM 第 12–16 层 AUC 0.997（按声学条件整组留出）；512 条误报里探针判"不在场"的 72%（成对条件内 83%）。
- **决定在第 16–22 层成形**（logit lens）；误报在第 18 层几乎平手，之后翻向出字。
- **编码器深层才有说话人信号**：注册段与混合段平均表示的余弦区分目标在场，浅层 AUC 0.65，第 15 层 0.86，第 24 层 0.89。
- **探针门控不能推广**（task 05）：只用 v12 拟合的第 12 层探针，在跟错人集上 t=0.1 去掉 33/146 条误报却多漏 112/4,953 条；场景 TS 11/18 对 12/1,823。不上线。
- **后续 GRPO 是在挪门槛**（task 08）：给"两轮相加"的 ` None` 加固定 logit 偏置得到误报–漏识曲线。v17 avg3（误报 350 / 漏识 3.13%）落在曲线上；v18 与两分支合并在同样误报下漏识少 0.4–0.7 个百分点，但总 CER 都高于"两轮相加"。只想少出错字时，给 ` None` 加偏置是零训练选项（+1.0：误报 465→353，漏识 2.31%→2.99%，脚本口径）。

## 四、推理时干预（tasks 06–07）

- **steering**（task 06）：方向只用 v12 拟合，在跟错人集、场景 TS 上评估。最好的是第 12 层、按探针不确定度缩放的版本：跟错人集误报 −43/148、误伤 19/4,952；场景 TS −5/18、误伤 1。最优层和强度随集合变化（第 16–18 层强推在跟错人集上误伤 274–346 条），且该设置是看留出集挑的。小幅净正、不稳定，不上线。
- **加强对注册段的注意力**（task 07）：第 18–21 层把误报的注册段注意力拉到正确拒识的水平（×3）或 2.4 倍（×10），只翻转 1–5/506 条，与压低注意力的效果相当；差异最大的 5 个头单独加强无效。第 12–21 层一起 ×10 才有特异效果（55 条，对照随机块 24、混合段 5）。"少看注册段"是相关现象，不是误报的原因。

## 八、相似嗓音负样本与 GRPO 更新归因（tasks 11–12，v21–v25）

误报主要来自"嗓音像目标的干扰人"（task 09），于是建了相似嗓音干扰人表（task 11），从 SFT 073 avg3 起用 v15 配方加相似嗓音负样本训练。结果：

| v12 CER / 误报 / 漏识（条） | v15 | v23 同语料 ×15 | v24 半数在线 | v25 挖掘计划 | S+Δ25+Δ16 | 两轮相加 |
|---|---|---|---|---|---|---|
| | 13.19 / 293 / 479 | 13.92 / 219 / 689 | 13.25 / 364 / 497 | 14.21 / 203 / 721 | 13.54 / 256 / 612 | **12.46 / 453 / 324** |

每一轮都是用漏识换误报。S+Δ25+Δ16 和 S+Δ22+Δ16 都落在"两轮相加"加 None 偏置的曲线下方：同样误报下漏识更多，不如直接加偏置。

**原因（task 12，梯度归因）：**
- 在 S 上，目标缺席题"出不出字"这一步的梯度，推正样本和推难负样本一样多（比值 1.04–1.11，相似嗓音题与普通缺席题相同，各模块相同），单步信号只能挪门槛。
- 误报转写文字的负梯度对这一决策几乎没有作用。
- 各轮实际更新带来的区分主要落在易负样本上，位置在 LLM 第 10–19 层，音频编码器几乎不动。
- v25 相对 v15 多出的效果约三分之二是整体平移。

误报的根子在说话人表示（task 09），GRPO 的 presence 信号够不着那里，所以继续调配比和负样本难度不会有本质改进。

**成对题（同一混合段换成相似嗓音注册）：**
- 编码器其实能分开真注册和相似嗓音注册：末层余弦 AUC 0.93–0.95，但模型在约 67% 的这类题上仍出字。
- 成对题直接放进 GRPO 没用：在场那一半全对、没有梯度，只剩更强的"说 None"。
- 显式成对 margin 损失（真注册出字、相似注册输出 None）能把难负样本推向不出字（+100）、同时把正样本推向出字（−136），是目前唯一有区分的训练信号。
- 只对编码器做说话人对比，对决策仍以平移为主。

**SFT A/B（task 13）**：把成对 margin 损失加进 SFT（v66），对照为同样续训但不加损失的 v64。v12 上成对组 14.66 / 215 / 770，对照 14.12 / 438 / 495。给对照加 None 偏置、调到同样误报时，成对组少漏 42 条（698 对 740，约 −6%），但难负样本误报基本不变（95 对 97）。收益主要在注册被污染或太短的正样本上。有一点真实区分，但没有打中"嗓音像目标的人"，也没有超过"两轮相加"。下一步需要直接作用于编码器说话人表示的训练信号，例如相似嗓音的对比损失，或成对的"同一混合段换注册"题，让整体平移的分量互相抵消。
