# GRPO 第七到第九轮与权重合并：SFT 之后的稳定收益（2026-11-03 至 11-04）

**结论：GRPO 在 SFT 推不动之后仍能拿到稳定收益，第七、八、九轮三次都复现了。** 收益集中在 TS（v12、英文 TS）、热词（hotword-bench 召回）和抗幻觉（空参考误报、鼎桥真实空白、咳嗽呼吸 / 人群噪声误输出）上。代价也稳定：远场英文 CHiME-4 的空输出比例上升。

**交付候选是 v9 插值 50%**：起点 066 avg3，加上第九轮 GRPO 增量的一半。它在中文、TS、热词、抗幻觉上全部好于或持平 10.28 交付版（054 avg3）。唯一没过的守门项是 CHiME-4 空输出：2.42% 对 2.20%，WER 6.59 对 7.17 反而更好。这 0.22 个百分点算不算通过，由用户定。权重合并（本机 6 种方法）没有找到更好的折中。

对象：起点 SFT 065 avg3（第七、八轮）与 066 avg3（第九轮）；评测都走部署推理栈（vLLM 0.18.0，bf16，贪心），AmphionEval v3 口径。执行记录在 `runs/amphionasr2-grpo-20261101/tasks/{17-grpo-v7,21-grpo-v8-nobabble,22-grpo-v9-from066}/`（不入库），关键指标与 run id 见 `results.json`。

## 二、执行与判读

| 轮次 | 做了什么 | 结果 | 决定 |
|---|---|---|---|
| 第七轮 | 起点 065 avg3，按方向重挖五份计划（热词、非人声、漏识、TS 缺席 / 在场），400 步，只存权重 | 相对 065：v12 13.30 → 12.66，英文 TS 13.76 → 12.77，hotword-bench 召回 83.4 → 87.3，空参考误报 2188 → 1357；CHiME-4 空输出 2.88% → 6.67% | 收益成立，CHiME-4 回退要找原因 |

| 权重合并 | 本机 6 种：插值 0.25 / 0.75、任务向量 066 + (v7 − 065)、两轮增量平均、TIES、DARE（SLERP 与插值 50% 等价，未评） | 都沿"GRPO 增量用了多少"排成一条线：增量越大 v12 / TS 越好、CHiME-4 空输出越高（TIES 5.53%、tv7 4.92%）；只有实际只带 61% 增量的插值 0.25 过守门，各项基本回到 066 | 合并不能打破 CHiME-4 的取舍。任务向量迁移有效：tv7 不经训练拿到与 v9 相当的收益，以后 SFT 迭代可以先叠 GRPO 增量再决定是否重训 |

- bf16 量化：GRPO 增量里约 65% 的非零元素只有 1 个 bf16 ulp，按比例插值会被截断（插值 0.25 实际只带 61% 的增量，插值 0.75 几乎等于 v9 avg3）。
- 鼎桥 `e警保` 回退（`tdtech/badcase@v3-20261104`）：表里有 `e警保` 时所有 GRPO 候选与 SFT 一样基本全对；表里只有近音词"义警"、没有 `e警保` 时所有版本都会错，这是两个词读音相同，线上词表已去掉"义警"，不作模型守门。

## 三、修复

- 第九轮第一次执行在第 273 步崩溃：GRPO 采样出了音频占位符（`<|audio_start|>` 等），打分前向的音频位置多于音频特征，`masked_scatter` 断言失败。修复：采样时屏蔽 `<|audio_start|>` `<|audio_end|>` `<|audio_pad|>`。transformers 采样路径见 9a9e409，进程内 vLLM rollout（第九轮实际使用的路径）见 012e576。第九轮第二次执行用的快照只含前者，跑完 400 步；102,656 条采样中仍有 8 条带占位符，没有触发崩溃。之后的执行用含两处修复的快照。
