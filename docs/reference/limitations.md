# 当前训练数据限制

已完成 Catalog 在线数据入口、YAML 配方、波形与特征增强、SFT 混合 / 动态 batch
及分布式采样位置恢复。旧离线数据生成链路已移除。

尚未支持：

- 大规模物理 shard 的按片懒加载；目前元数据和本轮索引计划驻留内存。
- GRPO 的来源混合与动态 batch；当前使用原生 generation-group sampler。
- 新采样器下的 sequence parallel / tensor parallel。
- 验证集的动态槽位分桶；验证混用不同槽位数时需每卡 batch size 为 1。
- 随训练 step 自动变化的来源权重。

小规模训练及恢复一致性验证不等于完整多任务效果验证。新增模型、任务和推理后端
仍应按具体使用范围验证，不据此声称与历史项目的任务指标完全一致。
