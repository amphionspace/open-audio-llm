AmphionASR 打榜评估报告

日期：2026 年 11 月 25 日

报告摘要

AmphionASR 是 Amphion 在 Qwen3-ASR-1.7B 上微调的语音识别模型，主打目标说话人识别、热词和复杂声学环境。为了借公开榜单提升 Amphion 的知名度，我们按 Hugging Face Open ASR Leaderboard 的口径完整复现了它的评测，并把 AmphionASR 与开源同类模型、7 家商用语音 API 放在同一批数据上做了逐条对比。本报告给出它的现状、与各项第一名的资源对比、真正领先的地方，以及建议的打法。

结论

  • 能不能拿第一，取决于哪一项第一，各项第一背后的资源差别很大。
    • 英文榜开源第一：资源上我们具备条件。现在的开源第一 Musci-ASR 和排第 16 的 orukqwen，都是在 Qwen3-ASR-1.7B（也是我们的底座）上，用公开数据做强化学习微调出来的；orukqwen 第一版只用了 54.6 小时英文和 14.3 个 A100 卡时。我们没拿到，是因为 11.17 是为业务训练的（中文、目标说话人、警务），从没针对这个榜做过，不是缺资源。建议单独做一个“榜单版”去争，约 3 周。
    • 英文榜全榜第一、多语种榜第一：存在真实的资源差距。这两项第一都是商用 API（Zoom、Azure），用的是规模未公开的专有数据；开源里最好的 NVIDIA 用了 172 万小时、77 种语言的数据，其中包括采购的数据。我们的训练数据约 7 万小时，几乎全是公开语料，以中英为主；德、法、意、葡、荷、印地语基本没有。要争这两项，需要先投入数据和算力。
    • 中文列：数字上能超过，但不能这样报。恢复实验做到 1.57，低于第一的 1.89，但其中一半靠 AISHELL-1 的测试句出现在训练数据里；干净口径下我们与底座持平。
  • 我们已经明显领先的是目标说话人识别：只转写指定的人，其他人说话不写出来。在约 5 万条中英测试上，中文 44 个场景组全部最好（含并列），英文 40 组中有 39 组最好；真实会议录音上错误率比开源同类低 41%–80%，商用 API 没有这项能力。公开榜单不测这一项。
  • 建议两条线并行：一是做英文榜单版，争开源第一，现有资源可做；二是开源 AmphionASR、发布目标说话人识别评测集和排行榜并配技术报告。全榜第一和多语种第一需要的数据与算力单独评估，由领导决定是否投入。

五、建议方案：两条线并行

A 线：英文榜单版，争开源第一。资源已经具备。从 Qwen3-ASR 底座出发，不改交付模型；用榜单领域的公开训练集，按榜单的整理稿风格做强化学习微调，只用开发集选模型，另用榜单没用过的数据核验，避免被认为是刷榜。参考：orukqwen 第一版只用 54.6 小时英文、14.3 个 A100 卡时，榜上排第 16；第二版继续强化学习后，7 个公开集从底座的 5.75 降到 5.42。Musci-ASR 降到 5.15。我们的目标是进入开源前三，争第一。

B 线：目标说话人识别赛道。由 Amphion 开放评测、定义这个赛道：开源 AmphionASR 权重，发布评测集、排行榜和技术报告。

C 项：全榜第一、多语种第一。需要先投入数据（采购或大规模处理公开多语种数据）和更多算力，建议单独立项评估成本，再决定是否做。

时间为预估，前提是两条线各有一位同事负责。A 线的算力在现有 2 个节点内。

已经具备

  • 与 Open ASR Leaderboard 同口径的本地评测，提交前可预估名次
  • 强化学习微调流程（交付模型已用过多轮）和 16 张 A800
  • 中英目标说话人识别测试集（约 139 小时）、AmphionEval 评测代码
  • 7 家商用 API 和小米 CocktailASR 的全集结果与逐条预测
  • 公开测试集去重工具；权重可以公开（负责人已确认）

还要做

  • A 线：榜单领域训练数据、榜单版训练与提交
  • B 线：公开版评测集、流水线基线、发布包、排行榜页面、技术报告
  • C 项：多语种和全榜第一的数据与算力成本评估

风险与应对

  • A 线不一定能拿到第一：开源第一 5.15 是别人在同一底座上做出来的，说明可行，但最终名次要看实测。榜单还有两个私有测试集由维护方评测，我们只能预估公开部分。
  • 被看作刷榜：测试集不参与训练和选模型，额外用榜单没用过的数据核验，训练数据来源在模型卡里写清楚。
  • B 线的公信力与公平性：评测集、代码、全部预测公开；商用 API 没有指定说话人的功能，要补流水线基线，并单列“目标单独说话”的对照组，那一组里我们英文并不领先，照实展示。
  • 数据许可：部分榜单领域训练集（如 SPGISpeech）和部分会议、噪声语料限制商用或再分发，用之前逐一核对。

六、需要决定

  1. 是否启动 A 线：英文榜单版，目标开源第一，现有资源可做，约 3 周。
  2. 是否同意 B 线：开源权重 + 目标说话人识别评测集和排行榜 + 技术报告。
  3. 是否为全榜第一和多语种第一立项评估数据与算力投入。
  4. 两条线的负责人和期望发布时间。
