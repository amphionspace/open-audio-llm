AmphionASR 打榜评估报告

日期：2026 年 11 月 25 日

报告摘要

AmphionASR 是 Amphion 在 Qwen3-ASR-1.7B 上微调的语音识别模型，主打目标说话人识别、热词和复杂声学环境。为了借公开榜单提升 Amphion 的知名度，我们按 Hugging Face Open ASR Leaderboard 的口径完整复现了它的评测，并把 AmphionASR 与开源同类模型、7 家商用语音 API 放在同一批数据上做了逐条对比。本报告给出它的现状、真正领先的地方，以及建议的打法。

结论

  • 不建议继续在 Open ASR Leaderboard 上投入训练。这个榜只测普通转写，以英文和欧洲语言为主。AmphionASR 在上面英文排第 25 名，比自己的底座（第 17 名）还低；就算全部恢复，也只能回到底座的位置。
  • AmphionASR 真正领先的是目标说话人识别：只转写指定的人，其他人说话不写出来。在约 5 万条中英测试上，中文 44 个场景组全部最好（含并列），英文 40 组中有 39 组最好；真实会议录音上错误率比开源同类低 41%–80%，商用 API 没有这项能力。
  • 建议换一种打法：开源 AmphionASR 权重，发布 Amphion 的目标说话人识别评测集和排行榜，配一份技术报告。Open ASR Leaderboard 只在发布后如实提交一次，作为参考。

二、我们领先的地方：目标说话人识别

场景是会议、多人对话、旁边有人说话或放音乐的时候，只转写指定那个人。用户先录 5 秒注册音，模型据此判断谁是目标。

商用 API 都没有“只转写指定的人”的接口，只能把混合音频整段转写，别人的话全算作错误，所以错误率会超过 100%。正式发布时会补上“说话人分离 + 声纹匹配 + 识别”的流水线基线。

四、建议方案

思路是让我们的强项能被公开衡量：由 Amphion 定义这个赛道并开放评测，比在别人的普通转写榜上排第 25 更能建立影响力。

时间为预估，前提是有一位同事负责报告写作和对外发布。

已经具备

  • 中英目标说话人识别测试集（约 139 小时）和 AmphionEval 评测代码
  • 7 家商用 API 和小米 CocktailASR 的全集结果与逐条预测
  • 与 Open ASR Leaderboard 同口径的评测，提交前可预估名次
  • 公开测试集去重工具；修复了 FLEURS 中文训练文本的括注错误
  • 权重可以公开（负责人已确认）

还要做

  • 公开版评测集的裁剪与许可核对
  • 流水线基线
  • Hugging Face 发布包与排行榜页面
  • 技术报告与对外发布

风险与应对

  • 自建自评的公信力：评测集、评测代码、全部模型的逐条预测都公开，基线按各家官方推荐的方式调用，第三方可以复现。
  • 对比公平性：商用 API 没有指定说话人的功能，直接比会被质疑。所以要加流水线基线，并单列“目标单独说话”的对照组；那一组里我们英文并不领先，照实展示。
  • 来源许可：部分会议和噪声语料可能限制再分发，能公开的范围要核对后才能确定；不能再分发的部分只发生成脚本。

五、需要决定

  1. 是否同意这条路线：开源权重 + 自建目标说话人识别评测集和排行榜 + 技术报告。
  2. 由谁负责技术报告和对外发布。
  3. 期望的发布时间。
