# 07-enroll-patching：注册段注意力的因果干预

## 结论

- **"误出字是因为决策时少看了注册段"这个假设基本不成立。** 第 18–21 层把决策位置对注册段的注意力抬到正确拒识的水平甚至更高（k=3 时 0.052→0.110，拒识为 0.091；k=10 时 0.217），506 条误出字里只翻回 1–5 条。这和批内数值噪声是同一量级：这几条的基线 None margin 都是 −0.25 nat 的近平局，而且把注意力**压低**（k=0.33）也会"翻回" 8 条。误出字 None margin 的平均变化只有 +0.04～+0.08 nat，误出字到判定边界的中位距离是 2.0 nat。
- 注册段注意力的差异更像决策的**结果或伴随信号**：正样本对注册段的注意力（0.038）比误出字（0.052）还低。误出字介于两者之间，也就是说注意力跟着模型"倾向输出什么"走。
- 在第 12–15 层加强注意力能翻回 3–5% 的误出字，但加强混合段或随机块的效果同样大甚至更大（随机块 k=10 翻回 7.9%），**没有特异性**。
- 只有第 12–21 层一起加强时出现一个**小而特异**的效应：k=10 翻回 55/506（10.9%），随机块 24、整段混合段 5。注册段加强让误出字的 None margin 平均 +0.46 nat，混合段 / 随机块分别是 −1.84 / −1.43 nat；拒识样本变成出字 3 条（混合段 19 条）。这需要把注册段注意力放大到基线的 4 倍才能拿到约 6% 的净效应（55 − 24 = 31 条），不足以解释误出字。
- 正样本几乎不受影响：所有设置下变成漏识别的都只有 0–2/1000 条。所以"每丢一个正样本能翻回几个误出字"这个比值没有意义，比较特异性要看误出字翻回数和 None margin 的变化方向。
- 头级分析：第 18–21 层里，拒识与误出字注册段注意力差异最大的 5 个头是 L19H5、L18H7、L21H9、L18H12、L20H13，它们占 18–21 层全部 64 个头差值总和的 50%。只加强这 5 个头（k=1.5–10）翻回 0–2 条，比随机 5 个头（0–9 条）还少，**没有复现任何效应**。
- 激活修补（任务 3）**跳过**：v12 的 26,750 条样本中每个 mixture 都只出现一次（cut 各不相同）。pos/neg 配对用的是不同的干扰人和不同的混合音频，不存在"同一混合段、换一个注册段"的干净配对。

## 方法

- 先做一次完整前向（截断到 `language`），得到基线决策和 KV cache。把 cache 裁到 `language` 之前，然后对每组设置只重跑 `language` 这一个 token（分批）。因为只有这一个 query，干预只作用在决策位置读取的内容上，之前所有位置的 K/V 都不变。
- 干预方式：在选定层（和头）的 attention mask 上，对目标 key 位置加 log(k)，再照常做 softmax 归一化。目标有三种：注册段（65 个 token）、整段混合段，以及混合段里与注册段等长的随机连续块（按样本 seed 抽取；混合段不足 65 个 token 时取整段，这种情况有 447 条）。
- 记录每组设置下最终 logits 的 argmax（` None` 或语言 token）、None margin，以及干预后第 12–21 层决策行的注册段和混合段注意力（对头取平均）。
