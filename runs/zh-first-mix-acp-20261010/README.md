# 中文优先配比：ACP 16 卡全参数

用户决定先在中文上单点突破（2026-10-10）。数据来源与上一轮相同，只调整配比：中文真实会话（AISHELL-4 20、AliMeeting 20、RAMC 8）由 29% 提高到 48%，英文真实会议（AMI 3、NOTSOFAR 2、CHiME-6 1）由 16% 降到 6%，词级合成中文 15、英文 3，旧合成 10，单人回放 18（回放内部比例沿用上一轮，英文 Common Voice 仍占 7.4%，待中文远场回放就绪后再调整）。采样种子 44。起点为 [续训 12000 步](../many-speaker-continue-acp-20261009/README.md) 的权重（新优化器），学习率 5e-6、500 步 warmup 后 cosine 至 24000 步，2×8 A800，每 2000 步保存并在开发机 GPU 6 选模。

## 为什么做

续训到 12000 步时，真实会议指标已进入平台期；与 MOSS 的中文差距（AliMeeting dev 排除复读 20–21% vs 15.6%）主要是远场替换错误、误检和说话人混淆。老师复查中文会议标注与中文远场数据（多通道视角、近讲模拟远场、真实远场单人回放）仍在准备，本轮先用现有数据检验“提高中文真实会话占比”在长训练上的收益，数据就绪后在本轮最优 checkpoint 上继续。

## 判定

与之前相同：只在排除复读的 AliMeeting dev cpER 连续 2 次高于起点（8000 合并模型，22.10%）+ 1 点时停止；复读条数不超过起点 17 + 6 的 checkpoint 才作为候选。结束评测 meeting-180s（重点看中文真实会议）、CHiME-6 dev、固定 338 条集。执行完成与质量达标分开记录。
