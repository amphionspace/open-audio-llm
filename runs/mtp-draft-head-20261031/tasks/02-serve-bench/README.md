## 无损（004，逐条比对原始输出，含 `language X<asr_text>` 前缀）

| 变体 | ASR c1 / c16 / c48（306 条中不同的条数） | TS c1 / c16 / c48（300 条） |
|---|---|---|
| 无投机，换并发 vs 自己 c1（批次不确定性的基线） | — / 8 / 5 | — / 1 / 2 |
| eagle k1 vs 同并发无投机 | 3 / 6 / 5 | 2 / 4 / 3 |
| eagle k2 | 3 / 4 / 9 | 2 / 5 / 2 |
| eagle k3 | 3 / 3 / 4 | 2 / 3 / 3 |
| suffix（同为无损方法） | 4 / 9 / 5 | 2 / 6 / 2 |

- 单路（c1，输入逐比特相同）下 eagle k1/k2/k3 都在同样 3 条 ASR、2 条 TS 上与无投机不同，suffix 是 4 / 2 条；差异都是近似并列的 token（如 角力/奖励、syrup/sirup、那/这，一条 TS 缺席样本 None/出字）。002 中把三档并发合计：eagle k1/k2/k3 与无投机不同的 ASR 条目分别 7/11/12 条，其中 6/7/8 条是无投机自己换并发也会翻转的条目（无投机共 8 条不稳定）；TS 为 7/5/6 条，其中 5/5/5 条（无投机共 5 条不稳定）。原因：校验时目标模型一次前向 k+1 个 token，注意力走的 kernel 与逐 token 解码不同，bf16 数值有微小差别，属于与批次大小同一类的不确定性，不是草稿头改变了输出。
- 流式回放（003，c1 时请求逐比特相同）：220 个请求中 eagle k2 / k3 / suffix 分别有 6 / 7 / 3 个输出与无投机不同。
- 识别率：003 流式回放 c16/c48 的 final 配对字错率无投机 12.69% / 12.60%，eagle k2 12.76% / 12.63%，eagle k3 12.78% / 12.70%，suffix 13.43% / 12.68%（272 / 811 段，含输入扰动随时序不同带来的差异，不作为准确率结论）。
