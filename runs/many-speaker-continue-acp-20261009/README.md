# 续训：5e-6 配方再训 24000 步

起点为 [many-speaker-long-acp-20261009](../many-speaker-long-acp-20261009/README.md) 5e-6 组 checkpoint-8000 的权重（选模任务保留的副本，不含优化器，新优化器重新 warmup）。学习率 5e-6、500 步 warmup 后 cosine 至 24000 步、全局 32 条、2×8 A800，配比与之前相同；数据配置为上一轮冻结配置的副本，只把采样种子 42 改为 43，使续训从约 1,800 万条样本池中抽取新样本，而不是重复上一轮的前 25.6 万条。每 2000 步保存并在开发机 GPU 7 选模。

## 为什么做

5e-6 组 8000 步内没有中文退化，排除复读后 AliMeeting dev 22.10% → 20.77%，NOTSOFAR dev 86.76% → 52.42%，复读条数 17 → 3–5，曲线仍在缓慢下降；8000 步只抽取了样本池约 1.4%。本轮在已确认的配方上用长训练观察收益，并作为后续老师打标蒸馏数据的训练基座。

## 判定

与上一轮相同：只在排除复读的 AliMeeting dev cpER 连续 2 次高于起点（8000 合并模型，22.10%）+ 1 点时停止；复读条数记录并限制候选（≤ 23；重跑实测标准差约 3 条），不触发停止。结束评测 meeting-180s、CHiME-6 dev、固定 338 条集，与起点和 MOSS 对照。执行完成与质量达标分开记录。

## 提前结束（2026-10-10）

训练在 checkpoint-12000 上传后经停止文件结束于第 12075 步（退出码 0）。原因：自 5e-6 组约第 6000 步起，排除复读后的 AliMeeting dev（20.3–21.2%）、NOTSOFAR dev（51.8–56.6%）、说话人数准确率与 DER 都在重跑噪声范围内波动，只有复读条数与同分布合成集仍在改善；用户随后决定转向中文优先（老师复查中文会议标注、中文远场数据），本实验的最优 checkpoint 作为下一轮起点。
