## 判定

- 选模与门槛沿用上一轮：目标 AliMeeting dev 不计复读 cpER；门槛 6–12 人合成不升 5 点、WenetSpeech / KeSpeech dev 各不升 1 点、复读不超过起点 + 6；加报高相似 1/3 窗口归错、重叠句字错、起点偏差。
- 评测改用已发布的 AmphionEval 0.10.0，所以 step 0 由 A 组选模重新测一次，B 组共用这份基线。单次评测约 1 点噪声，小于 1 点的差异不下结论。
- 读法：A 不退化、B 好于 A → 目标说话人任务有用；A 也退化 → 先查续训本身（优化器、学习率），再看 B。最终面板必须通过才算采用。
