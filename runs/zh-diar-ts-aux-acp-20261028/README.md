## 判定

- 选模与门槛沿用上一轮：目标 AliMeeting dev 不计复读 cpER；门槛 6–12 人合成不升 5 点、WenetSpeech / KeSpeech dev 各不升 1 点、复读不超过起点 + 6；加报高相似 1/3 窗口归错、重叠句字错、起点偏差。
