# 01 MTP 投机解码：无损、接受率与速度

- 输入：v16 avg3 主干与 `mtp/`；服务包 `shared/pack-mtp`；配置 `configs/spec-check.yaml`。
- 协议：同 mtp-draft-head-20261031 的 008。普通 ASR = 10.28 通用 ASR 评测 34 个数据源各 9 条（306 条，空系统提示）；TS = v16 avg3 的 v12 评测样本随机 300 条（新提示词，5 s 注册 + 混合段 ≤ 22 s）；温度 0，`max_tokens` 256；关闭 prefix cache，`--max-num-seqs 48 --max-num-batched-tokens 4096`，`gpu_util 0.30`。
- 环境：ACP GRPO 开发节点 GPU 0–3 各跑一个变体（同时进行）；vLLM 0.18.0（`vllm-serving`）。
- 入口：`scripts/run_spec_bench.sh attempts/<编号>`（先由 root 从 `checkpoint/mtp` 生成 `shared/draft-v16avg3`）。
- 完成条件：四个变体在两种模式、三档并发都有结果；MTP 与无投机逐条比对；W&B 远端核验。

## 结果（003）

**接受率**（每次校验接受的 token 数 MAL；逐位置接受率）

| 变体 | 普通 ASR MAL | 逐位置 | TS MAL | 逐位置 |
|---|---:|---|---:|---|
| k1 | 1.94 | 0.94 | 1.92 | 0.92 |
| k2 | 2.81 | 0.94 / 0.88 | 2.76 | 0.92 / 0.85 |
| k3 | **3.62** | 0.93 / 0.87 / 0.81 | **3.51** | 0.91 / 0.83 / 0.77 |

对照：mtp-draft-head-20261031 的 10000 步 EAGLE-3 草稿头（冻结 10.28 骨干单独训练）k3 为 3.43 / 3.31。

**速度**（独占 A800，每变体一张卡，四个同时跑）

| 模式 | 并发 | 无投机 均值 ms / token/s | k1 | k2 | k3 |
|---|---:|---|---|---|---|
| ASR | 1 | 103 / 185 | 77 / 249 | 66 / 289 | **63 / 303** |
| ASR | 16 | 233 / 1289 | 213 / 1416 | 176 / 1722 | **174 / 1734** |
| ASR | 48 | 423 / 2055 | 387 / 2271 | **373 / 2363** | 386 / 2301 |
| TS | 1 | 90 / 114 | 75 / 136 | 63 / 162 | **62 / 164** |
| TS | 16 | 281 / 569 | 293 / 547 | **256 / 628** | 270 / 595 |
| TS | 48 | 691 / 677 | 631 / 729 | 620 / 768 | **615 / 768** |

- 单路：k3 普通 ASR 均值 −39%、吞吐 +64%；TS 均值 −31%。
- 16 路：普通 ASR 吞吐 +35%（k2/k3）；TS 只有 k2 有收益（+10%），k1 比无投机慢。
- 48 路：普通 ASR +15%（k2），TS +13%（k2/k3）。
- 综合选 **k2**：高并发两种模式都不低于 k3，单路只比 k3 慢 3 / 1 ms。

**无损**（`compare.txt`）：单路 k1–k3 三个变体输出彼此相同，与无投机差 4 / 306 条 ASR、5 / 300 条 TS（编辑距离 8 / 19）。量级与无投机自己换并发相同（16 路 4 / 306、10 / 300），和 EAGLE 草稿头实验里的 3 / 306、2 / 300 同类，来自校验前向的计算路径。

## 未验证与风险

- 只测了 v16 avg3；每次换主干都需要该 checkpoint 自己的 `mtp/`（联合训练时自带）。
- 交付包运行时还没加这个草稿类；本实验的 `shared/pack-mtp` 是临时拼装的。
- 速度只在独占 A800 上测过，线上共享卡的净收益要在目标环境复测；TS 流式回放（预览滞后）没测。
