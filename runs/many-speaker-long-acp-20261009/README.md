# 长训练对照峰值学习率：两臂各 8000 步

两臂只差峰值学习率：LLM/aligner 1e-5、编码器 5e-6，对比 LLM/aligner 5e-6、编码器 2.5e-6。其余与 [many-speaker-real-mix-acp-20261009](../many-speaker-real-mix-acp-20261009/README.md) 相同：8000 合并模型起点、同一冻结数据配置（真实会话 45%、词级合成 25%）、warmup 500 步后 cosine、全局 32 条、2×8 A800。步数由 2000 增至 8000，每 1000 步保存并在开发机评测。

## 为什么做

2000 步的两轮无法回答学习率问题：每轮只覆盖约 6.4 万条样本，且选模指标被个别复读样本主导。同一 checkpoint 重跑，AliMeeting dev cpER 相差 3–5 点，几乎全部来自 1–2 条样本复读与否；排除复读样本后两次相差小于 0.5 点。排除复读后，中文相对起点（22.10%）的变化在 ±1 点内，6–12 人合成到 1500 步仍在下降。本实验用长训练和完整评测面板直接比较两种学习率。

## 判定

- 停止：只看排除复读样本后的 AliMeeting dev cpER，连续 2 次超过起点 + 1 点（23.10%）才停。
- 复读：记录全部面板复读条数；超过起点 17 + 3 的 checkpoint 不作为候选，但不触发停止。
- 候选中选 6–12 人合成 cpER 最低者，结束评测 meeting-180s、CHiME-6 dev、固定 338 条集，与起点和 MOSS 对照。
- 两臂比较在相同步数上进行；执行完成与质量达标分开记录。

## 任务

- `tasks/02-train-lr5e-6`、`tasks/02-train-lr1e-5`：ACP 训练。
- `tasks/03-select-lr5e-6`、`tasks/03-select-lr1e-5`：开发机选模（GPU 6/7，端口 8791/8801），停止文件在各自 `control/`。
