# 07 音频塔的干净原句表示损失（实验组）

## 假设

任务 05、06 说明了三件事：
- 输出层的信号（交叉熵、对干净输入的 KL）推不动编码器对目标的选择性。
- 老师的输出分布基本就是标注本身。
- 重叠时丢掉的字，信息是在编码器里丢的。

所以把信号直接放到音频塔的输出上：让音频塔看"注册 + 混音"时，每个音频 token 都接近起点音频塔看"注册 + 干净原句"时的 token。

- 上限：冻结的 LLM 拿到干净原句的表示，训练分布上文字 −log p 从 0.193 降到 0.065（任务 05）。
- 换注册之后，表示拉向的是"只有目标"的样子，等于直接训练编码器做目标提取。
- 冻结 LLM，避免任务 04 那样把 11.17 在 v12 上的能力训掉（任务 06）。

## 唯一主要变量

与 [08 对照](../08-frozen-llm/README.md) 只差数据配置里的 `objective.clean_teacher_feature_weight: 1.0`。

## 输入

- **配置**：[../../configs/train-feat.yaml](../../configs/train-feat.yaml)；数据配置 [../../configs/train-data-feat.yaml](../../configs/train-data-feat.yaml)。冒烟用 `smoke-train-feat.yaml`。
- **起点**：11.17。
- **数据**：v96（与 03/04 相同的来源和权重）。训练文本切到 final-v1，共 110 条来源；西语 15 条不在终版范围，保持原版。
- **冻结范围**：
  - 冻结 LLM（`--freeze_llm true`）；
  - 音频塔除卷积前端外都训练，学习率 5e-6（`--vit_lr`、`--aligner_lr`），余弦退火；
  - 普通识别的西语 KL（2.0）保留。
- **表示损失**：
  - 只用目标在场的在线混音 TS 样本：单句干净目标和场景池，与任务 03 相同。
  - 每条样本的损失 = Σ‖学生 token − 老师 token‖² / Σ‖老师 token‖²，覆盖全部音频 token（注册、SEP、混音）。
  - 老师是训练开始时音频塔的冻结 BF16 拷贝。
  - 按条加到交叉熵上，`token_mean` 归约下按该条的监督字数加权。
- **规模**：4 卡 × 每卡 8 条 × 累积 6，共 6000 步。与 08 同节点各 4 卡。
- **代码**：`shared/code-v2`（feat/ts-clean-teacher-kl 023232e）。

  - 客户 TS。

- 要回答的问题：表示损失能不能让编码器的选择性和重叠转写错误动起来，同时守门不退。

- `clean_feat` 从第 10 步的 0.45 降到 0.157，之后基本不动。
- 训练分布上的 TS 交叉熵 `ce_ts_positive`，07 全程比 08 高 0.004–0.006（最后 0.1855 / 0.1813）。
- 表示更接近老师，LLM 却并没有更容易读出目标文字。

解读：

- **表示损失没有起到预期作用。**
  - 重叠 ≥ 0.9 的转写错误：07 比 08 高 0.13，只在重叠 < 0.9 的几档略低（0.1–0.2）。
  - 误报多了 40 条，出错字里抄干扰人的比例从 8.3% 升到 11.3%。
- **编码器选择性没有上升，反而下降了**（v12 参考文本 teacher forcing，逐条配对 12,953 条，attempt 003）：

  | 重叠 ≥ 0.9 | 11.17 | 08 对照 | 07 表示损失 |
  |---|---:|---:|---:|
  | 参考 −log p / 字 | 0.793 | 0.848 | 0.859 |
  | 判定处 P(None) | 0.046 | 0.061 | 0.050 |
  | 换注册后参考 log p 下降 / 字 | 2.19 | 2.17 | 2.61 |
  | 换注册后重叠帧变化（1 − cos） | 0.294 | 0.297 | 0.212 |
  | 换注册后只有干扰人帧变化（1 − cos） | 0.202 | 0.206 | 0.117 |

  - 换注册以后，音频塔最后一层在混音帧上的表示变化更小：音频塔更不依赖注册了，没有学会"按注册挑人"。
  - LLM 的输出更依赖注册（换注册后参考 log p 下降得更多），但对 v12 参考文本的拟合没有变好。
  - 出错字里抄干扰人的比例上升，集中在干扰人比目标轻或差不多响的样本（`interf_gain_db` < 0：7.3% → 11.5%；0–3 dB：9.2% → 11.9%）；干扰人更响的样本没变（6.7% → 5.9%）。所以不是"留下更响的那个人"这种简单捷径。
  - 数据支持的部分：音频塔把训练集上的表示误差降到 0.157，靠的主要不是注册，因为换注册后的表示变化反而变小了。
  - 解释（未单独验证）：这样学到的变换在 v12 上丢掉了 LLM 原本用来分辨目标和干扰人的信息，所以抄干扰人和误报变多。训练数据里有什么不靠注册就能分出目标的线索，还没有查。
- **冻结 LLM 也挡不住从 11.17 接着 SFT 的退化。** 08 在每个重叠档、包括无重叠，都比 11.17 差，误报 + 漏识从 699 回到 791。
  - 这与复盘的历史数据一致：SFT 出来的模型误报 + 漏识一直在 802–894，只有 GRPO 和合并出来的模型能更低。
  - 11.17 的 699 来自 GRPO v18 骨干，它的音频塔也来自 GRPO v18。接着做 SFT，哪怕只训音频塔，也在把 GRPO 的收益还回去。
  - 冻结 LLM 的唯一收益是英文 TS 误报守住了（660，04 是 805）。04 的音频塔学习率只有 2e-6，比 08 的 5e-6 还小，所以 03/04 的英文误报上升主要来自 LLM 的更新。
- **基座 KL 不是退化原因。** 回放 KL 的参照是基座 Qwen3-ASR，但基座的中文普通识别（4.18）比 11.17 好，训练后反而离基座更远（4.55），没有被拉回基座。
