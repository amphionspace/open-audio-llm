# 19 以注册为条件的目标人提取前端（掩码预测）

## 要回答的问题

任务 18 证明了两件事：
- 重叠音频可恢复：理想比例掩码下 11.17 只错 5.76%，原混音错 14.50%；
- 瓶颈在编码器：它分不出目标人，用文本交叉熵也训不出来。

用户 2026-11-22 决定走掩码预测这条路试试：训一个以注册音频为条件的提取模型，放在 11.17 前面，把目标人的声音抽出来再识别。11.17 本身不动。

## 输入

- **训练数据**：v12 生成器在线现生成场景（[tse_data.py](../../scripts/tse_data.py)）。
  - 说话人池换成各语料的 train 划分，KeSpeech 不设 250 人上限，共 26,585 个说话人。
  - 用配方里 55 种目标在场、不带非线性录音链效果的场景类型，包括目标单独说、轮流说这些不重叠的情况。
  - 训练目标是目标人的单独音轨（带混响和增益，不含干扰人和噪声）。
- **验证**：300 条 dev 划分说话人的场景（aishell、kespeech、magicdata 的 dev），与训练和测试都不重叠（[tse_gen_dev.py](../../scripts/tse_gen_dev.py)）。
- **测试**：
  - 重叠集：任务 18 的 615 条 v12 重叠 ≥ 0.9 样本，有精确单独音轨。
  - 副作用集：v12 主数据集里，目标在场且不重叠的 200 条、目标在场且重叠 < 0.6 的 200 条、目标不在场的 200 条（[tse_export_safety.py](../../scripts/tse_export_safety.py)）。
- **识别**：11.17 TS（pack-mtp，与守门相同），一次请求同时解码原混音、提取结果和"提取 + 0.15 倍原混音"（remix）三种输入（[run_tse_eval.sh](../../scripts/run_tse_eval.sh)、[tse_report.py](../../scripts/tse_report.py)）。

## 进展与结果

所有训练都在 ACP `pt-0vbbz0mo` 上，8 卡数据并行，在线生成场景。

| 版本 | 结构与训练 | 验证集信号质量提升（理想比例掩码 +14.3 dB） | W&B |
|---|---|---:|---|
| 1 | BLSTM 掩码（3030 万参数），说话人向量从零学，压缩幅度损失 | 第 4000 步 +0.50 dB，停 | `qt7fq36s` |
| 2 | 同 1，加冻结的 CAM++ 中文声纹向量，波形 SI-SDR 损失 | 第 6000 步 +3.56 dB，第 8000 步 +3.76 dB，停 | `y71kc2sn` |
| 3 | 预训练 MossFormer2（5640 万参数）加入口 FiLM 声纹条件，4 秒片段 | 第 3000 步 +0.70 dB，停 | `qb223fxa` |
| 4 | 3 加掩码网络内部 3 处 FiLM，接着 3 的第 3000 步训 | 第 3000 步 +3.36 dB，第 4500 步 +3.43 dB，训练中 | `vgtaf993` |

- 第一版学成了"压掉噪声和静音"：损失从 0.74（掩码全 1）降到 0.17，但没学会按注册区分说话人。
- 预训练 MossFormer2 不经微调，盲分离在验证窗上就有 +9.8 dB（两路取对的那一路）。它的难点是声纹条件学得慢；在内部多处注入后才明显加快。
- CAM++（ModelScope `iic/speech_campplus_sv_zh-cn_16k-common`，Apache-2.0，SHA-256 `3388cf5f…`）。在验证集上，劣化注册与目标人音轨的区分度 AUC 是 0.925。

**测试**（11.17 转写错误，[95%] 为与原混音逐条配对的 bootstrap 区间）：

| | 原混音 | 第二版第 6000 步：提取 | 第二版：remix、空则回退原混音 | 第四版第 4500 步：提取 |
|---|---:|---:|---:|---:|
| 重叠 ≥ 0.9，全部（615） | 14.27% | 16.83% | **13.35%**（−0.92 [−2.33, +0.38]） | 23.19% |
| 1 个干扰人（305） | 11.02% | 10.97% | **9.39%**（−1.63 [−3.67, +0.11]） | 20.64% |
| 2 个干扰人（310） | 16.63% | 21.08% | 16.22%（−0.41 [−2.34, +1.32]） | 25.03% |
| 不重叠 + 轻度重叠（400） | 8.75% | 9.18% | 8.59%（−0.15 [−0.81, +0.47]） | 11.94% |
| 目标不在场，误报率（200） | 4.5% | 3.5% | 4.5% | 2.0% |
| 测试集信号质量：混音 → 提取 | −4.13 → | +0.18 dB | | −2.05 dB |

- **第二版**：没有副作用，1 个干扰人时有接近显著的改善，2 个干扰人基本不变。
  - 单用提取结果在 2 个干扰人时更差，因为失真比去掉的干扰更伤识别。
  - 混回 0.15 倍原混音，并在 11.17 判定为空时回退原混音，是当前最好的用法。
- **第四版**：16% 的样本信号质量下降超过 5 dB（第二版 0.2%），就是抽错了人。
  - 11.17 收到注册人以外的声音会正确地输出空：615 条里 78 条为空，原混音只有 16 条。多出来的错误几乎全是漏字（5.2% → 14.9%），替换反而减少（8.5% → 7.5%）。
  - 所以它分离得更干净，但挑人不可靠。
- 第一版第 4000 步只用来验证流程，结果见 `report_v1s4000.json`。

## 结论（2026-11-22，第一轮）

1. **方向成立，但第一轮的提取质量远不够。**
   - 测试集上最好的提取模型只把信号质量提高约 4 dB，理想比例掩码是 +14 dB；
   - 转写上最好只有 1 个干扰人时约 1.6 个点的改善，不显著；2 个干扰人基本没动。
2. **难点在"挑对人"，不在"分开声音"。**
   - 预训练分离模型本身分得开（+9.8 dB），但在两三个人里稳定选出注册的那个人，比分离难学；
   - 第四版 16% 抽错人，第二版几乎不抽错，但分得不够干净。
3. **11.17 对提取失真很敏感。**理想比例掩码的失真很温和，所以能到 5.8%；学出来的提取结果要么失真大，要么偶尔抽错人，都会被放大成识别错误。"混回一点原音、为空则回退"能挡住大部分损害。
