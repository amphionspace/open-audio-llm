# 17 先分离再识别：现成分离模型做前端的上限（只评测）

## 要回答的问题

v12 重叠 ≥ 0.9 的转写错误集中在 2 个以上干扰人同时说话的样本上。模型连训练数据在这一档都拟合不好（每 token 损失 0.27，无重叠 0.03），GRPO 和 SFT 都只能挪动很小一点。

所以要先弄清一个问题：这部分信息到底能不能从音频里找回来？如果先用专门的分离模型把混音拆开，再交给 11.17 识别，能不能明显好于 11.17 直接识别原混音？

- 如果明显更好，说明信息在音频里，瓶颈是我们模型自己的分离能力，值得做"目标说话人提取前端"。
- 如果不更好，可能是现成模型和我们的数据不匹配，不能据此判定信息找不回来。

## 输入

- **样本**：11.17 的 v12 评测 run `run-20261117T032925Z-961b82b3` 里，中文、目标在场、目标重叠 ≥ 0.9 的样本。按干扰人数各随机抽 400 条（1 个、2 个干扰人），种子 20261122。
  - 导出脚本：[sep_export_subset.py](../../scripts/sep_export_subset.py)。注册按评测截 / 补到 5 秒。
- **分离模型**：MossFormer2_SS_16K（ClearerVoice-Studio，Apache-2.0，两路盲分离）。
  - 权重 SHA-256 `00a3a48b…a11a`，与 AmphionTSE P55 记录的相同。
  - 代码固定在 commit 6b3774d，脚本 [sep_mossformer2.py](../../scripts/sep_mossformer2.py)。
  - 分段解码：4 秒窗、3 秒步长，用 1 秒重叠区的相关性对齐两路顺序并交叉淡化。
  - 2 个干扰人的样本先拆成两路，再对每一路各拆一次，共 6 路候选。每路候选的音量都调回混音的 RMS。
- **识别**：11.17 TS 模式，即 gate 用的 pack-mtp 服务栈，贪心解码、max_tokens 256，与评测相同。输入是 [5 秒注册 | 候选]。
  - 脚本：[sep_asr_probe.py](../../scripts/sep_asr_probe.py)、[run_sep_asr.sh](../../scripts/run_sep_asr.sh)。
  - 同一批样本也重跑了原混音（orig），用来核对能否复现评测输出。
- **打分**：[sep_ceiling_report.py](../../scripts/sep_ceiling_report.py)。口径同任务 10：AmphionEval 中文切分，(替换 + 漏字 + 多字) / 参考字数，空输出按全漏计。

候选的挑法：
- **按参考答案挑（oracle）**：挑错得最少的一路，是分离前端的上限。
- **按置信度挑（conf）**：在输出非空的候选里，挑 11.17 平均 token 对数概率最高的一路。
- **conf+orig**：同上，但原混音也作为一路参与挑选。

## 完成条件

两个子集都报出 orig、oracle、conf、conf+orig 的错误率，以及与 orig 逐条配对的 bootstrap 区间（2,000 次）。W&B 远端核验。

## 结果

**现成分离模型做前端，明显比 11.17 直接识别原混音差，即使按参考答案挑最好的一路也一样。**

| 转写错误 | 1 个干扰人（400 条） | 2 个干扰人（400 条） |
|---|---:|---:|
| 评测输出 | 10.61% | 16.78% |
| 重跑原混音（orig） | 10.74% | 16.92% |
| 分离后按参考答案挑（上限） | 15.97%（+5.23 [+1.71, +9.06]） | 32.07%（+15.15 [+11.83, +18.69]） |
| 分离后按置信度挑 | 17.31%（+6.58 [+3.02, +10.19]） | 39.46%（+22.54 [+18.65, +26.34]） |
| 原混音也参与挑 | 10.42%（−0.32 [−2.52, +1.87]） | 24.77%（+7.85 [+5.11, +10.74]） |
| 每条取原混音与最好一路中错得少的（融合上限） | 7.02% | 13.04% |

- 复现没问题：重跑原混音和评测输出只差 0.1 个点。
- 分离后变好的样本 1 个干扰人是 33/400，2 个干扰人是 58/400；变差的分别是 64/400 和 192/400。
- 11.17 自己错得多（≥ 30%）的样本上，分离确实能帮上忙：1 个干扰人从 70.6% 降到 47.1%（43 条），2 个干扰人从 68.5% 降到 62.2%（82 条）。
- 所以两者有互补：每条取较好的一个，上限是 7.0% / 13.0%。但按 11.17 的置信度挑，拿不到这部分收益。

## 结论

1. **现成的盲分离模型不能直接当前端用。**11.17 对原混音的端到端处理，已经比"公开分离模型 + 11.17"好得多。MossFormer2 训练于英文、干净、无混响的两人混音，v12 有底噪、混响和中文，还常是三人同时说话。分离引入的失真和分错，比留下的干扰更伤识别。
2. **"信息找不回来"仍不能下结论。**负结果可能来自数据不匹配。互补的样本说明，11.17 错得多的一部分样本在分离后能识别对，这部分不是物理上听不出来。
3. **要真正回答，需要在我们自己的数据上训的分离或提取模型。**例如用我们的在线混音（中文、底噪、混响、0–4 个干扰人，已能输出干净目标原声）微调 MossFormer2，或训一个以注册为条件的提取模型，再重复本任务。这是新的方向，代价约一个节点一天以上，需要用户决定。
