# 06 从 11.17 接着训，为什么在 v12 上变差（只诊断，不训练）

## 要回答的问题

任务 05 发现，04 对照组在训练分布的样本上比 11.17 拟合得更好（中文重叠 ≥ 0.9：−log p 0.268 → 0.252），在 v12 上转写错误却从 15.64 升到 16.68。以后不管加什么训练信号，只要还从 11.17 接着训，都要先解决这个问题。所以先分清是哪一种：

- **对 v12 本身的拟合变差了**：在 v12 参考文本上做 teacher forcing，−log p 也比 11.17 高。说明训练分布上的进步没有迁移到 v12，或者把 11.17 已有的能力训掉了。
- **拟合没变差，自由解码变差了**：v12 上 −log p 持平或更好，但实际输出更差。说明问题出在解码行为上，例如 GRPO 学到的东西被 SFT 冲掉了。

同时看编码器对注册的选择性（换注册后重叠帧的表示变化），是否因为解冻音频塔而改变。

## 结果

**结论：两组退化的原因不一样。编码器的目标选择性两组都没变。**

在 v12 参考文本上 teacher forcing（逐条配对，12,953 条）：

| 重叠 | 指标 | 11.17 | 04 对照 | 03 实验 |
|---|---|---:|---:|---:|
| 全部 | 参考 −log p / 字 | 0.633 | 0.727 | 0.642 |
| 0.6–0.9 | 参考 −log p / 字 | 0.616 | 0.742 | 0.615 |
| ≥ 0.9 | 参考 −log p / 字 | 0.793 | 0.910 | 0.790 |
| ≥ 0.9 | 排名 > 20 的字（%） | 4.32 | 4.82 | 4.08 |
| 全部 | 判定处 P(None) | 0.033 | 0.052 | 0.059 |
| ≥ 0.9 | 换注册后重叠帧变化 / 只有干扰人帧变化 | 0.294 / 0.202 | 0.293 / 0.201 | 0.295 / 0.209 |

v12 自由解码的字错拆分（复盘的 `decompose_errors.py`，口径与守门不同，只看相对变化）：

| | 替换 | 漏字 | 多字 |
|---|---:|---:|---:|
| 11.17 | 15,969 | 5,320 | 2,516 |
| 04 对照 | 17,185 | 4,605 | 3,439 |
| 03 实验 | 16,676 | 6,581 | 3,274 |

- **04 对照：对 v12 本身的拟合变差了。**
  - 参考 −log p 在每一档都比 11.17 高约 15%，而它在训练分布上反而更好（任务 05）。
  - 所以用 v96 数据从 11.17 接着做 SFT，会把 11.17 在 v12 这类数据上的能力训掉，训练分布上的进步迁移不过来。问题出在配方和数据，不在解码。
  - 它的错误更多是替换和多字：更敢猜。
- **03 实验：拟合没变差，是自由解码变差了。**
  - 参考 −log p 和 11.17 持平，排名 > 20 的字反而略少。KL 拉向模型自己看干净输入时的输出，起到了"别离开 11.17 太远"的约束作用。
  - 但自由解码时漏字多了 24%，而且分布在主测试集的各个子集，重叠 < 0.9 的增加（+715）多于 ≥ 0.9 的（+391）。
  - 结合判定处 P(None) 上升、看干净输入时熵上升（任务 05），它学会的是"拿不准就少写"，而不是听得更清楚。
  - 在参考文本前缀下，提前结束的情况三者都很少（每千字 ≤ 0.4 次），所以漏字不是"提前收尾"，而是解码途中跳过了片段。
- **两组的编码器选择性都和 11.17 一样**（≥ 0.9：0.29 / 0.20）。解冻音频塔、只用文本交叉熵或输出层 KL 训 6000 步，编码器对目标的选择性完全没动，与复盘里历史轮次的结论一致。

## 对下一步的含义

1. 输出层的信号（交叉熵、对干净输入的 KL）推不动编码器的选择性。要改善重叠转写，信号得直接作用在编码器表示上。例如：让编码器看混音时，在每一帧上的输出接近冻结的 11.17 编码器看"注册 + 干净原句"时的输出。
   - 任务 05 已经量出这样做的上限：冻结的 LLM 拿到干净原句的表示，训练分布上文字 −log p 从 0.193 降到 0.065。
2. 从 11.17 接着训，不能再放开 LLM 用 v96 数据做 SFT，那样会训掉它在 v12 上的能力。新的信号应当只训音频塔、冻结 LLM。普通识别用编码器表示的保持项守住。
