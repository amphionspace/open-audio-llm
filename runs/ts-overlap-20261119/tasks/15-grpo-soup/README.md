# 15 任务 13 与任务 14 的权重平均（不训练）

## 要回答的问题

任务 13 和任务 14 都是从 11.17 起的 GRPO，都带 ts-hard 难例计划，只差 ts-present 份额（0.06 / 0.12）。两者的出字门槛分别落在守门的两边：

| v12（守门 12.88 / 371 / 369） | 字错率 | 误报 | 漏识 | 重叠 ≥ 0.9 转写，与 11.17 之差 [95%] |
|---|---:|---:|---:|---:|
| 11.17 | 12.80 | 342 | 357 | — |
| 13 avg3（偏拒） | 13.04 | 277 | 411 | −0.35 [−0.54, −0.14] |
| 14 avg3（偏写） | 12.50 | 451 | 278 | −0.25 [−0.45, −0.05] |
| 13 interp050 | 12.87 | 306 | 384 | −0.19 [−0.34, −0.04] |
| 14 interp050 | 12.62 | 394 | 318 | −0.16 [−0.29, −0.03] |

两个模型起点相同，训练只差一项份额。把权重直接平均，出字门槛预计落在两者之间：若近似线性，误报约 364、漏识约 345。两边共有的转写收益也应保留。项目里以往的合并（如 11.17 本身）用的也是这种做法。

## 设计

[run_soup_evals.sh](../../scripts/run_soup_evals.sh)，用 `avg_ckpt.py` 做均匀平均；所有输入都带 mtp/ 时，MTP 模块也一起平均。

- **soup**：13 avg3 与 14 avg3 各一半。带 MTP，可直接交付。
- **soup-interp050**：soup 与 11.17 各一半（GRPO 增量 0.5）。门槛余量更大，转写收益更小。
- 评测同前：四套，两个候选并行。

## 完成条件（2026-11-22 评测前登记）

- **守门**：v12 12.88 / 371 / 369；英文 TS 误报 ≤ 655；中文普通识别 ≤ 4.39。
- **主指标**：v12 重叠 ≥ 0.9 的转写错误，逐条配对 bootstrap 显著低于 11.17（95% 区间上界 < 0）。
- 两个候选都达标时，选转写收益大的那个作交付候选（soup 带 MTP；soup-interp050 需要另配 MTP），再按交付流程打包。替换交付版本由用户决定。
