# 14 GRPO 难例计划 + 加大 ts-present 份额（压住出字门槛的漂移）

## 要回答的问题

任务 13（只用"差得多"的难例）让 v12 重叠 ≥ 0.9 的转写显著变好，逐条配对、2,000 次 bootstrap：
- avg3 − 11.17 = −0.35 [−0.54, −0.16]；
- avg3 − 任务 12 avg3 = −0.23 [−0.39, −0.07]；
- interp050 − 11.17 = −0.17 [−0.32, −0.02]。

但 GRPO 一直把出字门槛往"拒绝"推：漏识 411（avg3）、384（interp050），守门是 369。interp050 的字错率 12.87、误报 306 已经达标，只差漏识。

漏识随插值比例大致线性上升（11.17 357 → interp050 384 → avg3 411）。要靠插值压回 369，比例得降到约 0.2，那时转写收益也只剩约 0.08。所以要在训练里压住门槛漂移。

任务 12 的拆分显示，新增漏识集中在：没有干扰人（74 → 128）、近远讲（10 → 28）、短注册（60 → 87）。也就是目标人在场、但和注册音频不太像的情况。ts-present 计划正好推向"写"：它收的是目标在场、部分采样什么都没写的 TS 提示。
