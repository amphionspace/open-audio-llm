# 05 干净原句老师的信号对不对（只诊断，不训练）

## 要回答的问题

任务 03 加了干净原句 KL 之后，重叠转写反而比对照组差。训练日志里 KL 停在 0.11 左右，实验组的 TS 交叉熵也一直高于对照组。在定原因、决定要不要修之前，先直接量一下老师：

1. 老师（同一模型看"注册 + 干净原句"）对训练标注的把握，是否明显好过学生看混音？如果好不了多少，这个 KL 本来就没有多少可学的。
2. 干净原句在目标前后是数字静音（一半窗口有 0.5–8 秒前导、0.5–6 秒拖尾）。数字静音是不是让老师变差了？
   - 对照 1：垫一层很低的底噪（比目标低 30–50 dB），去掉数字静音。
   - 对照 2：只截目标那一段，不留前后静音。
3. 训练之后，两组模型在同一批训练分布的样本上有什么不同？

## 结果

**结论：老师本身是准的，数字静音也只是小问题。真正的问题是这个 KL 几乎没有带来标注之外的信息，而是把额外的权重压在学生根本听不到的那些字上。**

1. **老师准，而且几乎是确定性的。**
   - 在 11.17 上，看干净原句时文字部分的 −log p 为 0.065，看混音为 0.193；argmax 命中率 98.3% 对 95.5%。
   - 中文字里有 95.8% 老师给标注的概率 > 0.95，每字熵只有 0.048。
   - 所以老师的分布基本就是标注本身，没有"更密的监督"可蒸馏。复盘时以为老师能提供比参考文本更多的信息，这个前提不成立。
2. **KL 集中在学生听不到的字上。**
   - 学生 −log p > 3（即 p(标注) < 5%）的字只占中文字的 1.4%，却占学生与老师差距的 65%。
   - −log p 在 1–3 之间的字占 1.6%，差距占 23%。
   - 83% 的 KL 来自 `scene-full` 场景（占 50% 的字）。
   - 在这些字上，KL 和标注交叉熵推向同一个答案。KL 实际上是给"混音里已经丢了信息"的字再加一份交叉熵，等于逼模型猜。这与任务 03 训练日志里 KL 停在 0.11、降不下去一致。
3. **数字静音只有小影响。**
   - 中文重叠 ≥ 0.9 样本上，老师 −log p 为：数字静音 0.090，垫底噪 0.074，只截目标段 0.053。三者都远低于学生的 0.268。
   - KL 只从 0.353 降到 0.300–0.327。
   - 任务 03 README 里"老师输入不对"的推测，主因判断是错的，已在那里更正。
4. **训练后，同一批训练分布样本上（中文学生 −log p，11.17 / 03 实验 / 04 对照）：**

   | 重叠 | 11.17 | 03 实验 | 04 对照 |
   |---|---:|---:|---:|
   | 0 | 0.0335 | 0.0376 | 0.0360 |
   | 0–0.6 | 0.0427 | 0.0444 | 0.0412 |
   | 0.6–0.9 | 0.1045 | 0.1146 | 0.1006 |
   | ≥ 0.9 | 0.2677 | 0.2684 | 0.2517 |

   - 实验组连训练分布本身都拟合得比对照组差，0.6–0.9 档甚至比起点差，所以不是泛化问题。
   - 实验组看干净原句时更不确定了：熵 0.048 → 0.057，P(None) 0.013 → 0.028。对照组反而更确定（0.041）。
   - 对照组在训练分布上比 11.17 好（≥ 0.9：0.268 → 0.252），在 v12 上却变差（转写错误 15.64 → 16.68）。训练分布上的进步没有转化到测试集，原因见任务 06。
