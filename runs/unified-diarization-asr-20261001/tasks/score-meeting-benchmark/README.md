# 180 秒会议评测集结果（2026-10-08）

**结论：MOSS-Transcribe-Diarize 在所有部分都显著优于我们的模型。差距最大的是 6 人以上和英文会议；在 180 秒切段下，复读循环是我们模型独有的严重问题。**

## 指标与口径

AmphionEval 0.6.0 diarization 协议。cpER（按说话人拼接后的最小排列错误率，中文按字、英文按词、中英混合按混合单位）计入全部样本，从原始输出宽松提取说话人文字；DER（collar 0.25 s）只在时间完整解析的样本上计算。复读：同一字连续 30 次以上或 2–10 字片段连续 20 次以上。差异为按会议成对 bootstrap 95% 区间（未做多重比较校正）。我们的模型用 vLLM 0.18.0 进程内推理；MOSS 用官方固定提交 vLLM nightly（0.23.1rc1.dev949+g68b4a1d58）HTTP 服务。

## 主要问题

1. **6 人以上**：我们的模型说话人数几乎全错，倾向把多人合并；训练数据中 6–7 人仅占 0.38%，没有 8 人及以上。
2. **英文会议**：AMI 去掉复读后仍有 55–68%，说话人数准确率不足 30%。
3. **复读循环**：180 秒片段中少数样本输出同一字直到 4096 token 上限，单段错误率可超 300%，部署中该段输出不可用。
4. 三个模型之间差异主要来自复读条数，没有显著的能力差别（全参 2500 在 AMI 上因复读明显更差）。
