# 以 25500 为基座的新一轮 LoRA SFT

假设：每卡 4 条、不累积（方案 B）能提高 GPU 利用率，新 LoRA 能在 25500 基础上继续提升。

结果：执行 001 训练到约 7000 步，用户叫停。固定集（训练内评测，基线为 25500 的 21.17%）：500 / 2000 / 4000 / 6000 步为 21.65 / 21.11 / 21.79 / 21.48%，均无显著改善。GPU 利用率由 60–70% 升至约 96%，吞吐仅小幅提升。

结论：从 8000 之后的轨迹继续训练不能改善会议集；25500 本身比 8000 差。

证据：W&B `unified-diarization-sft-25500-001`；`attempts/001/artifacts/training/retention-evaluations/`；保留 checkpoint-7000（已上传）。
