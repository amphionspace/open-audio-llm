# 训练样本逐条 loss

用 8000 合并模型、训练模板逐条计算 loss：全部真实会议 + 3% 合成（单人 ASR 回放未覆盖）。

结果（执行 004）：AliMeeting `R1021_M1947` loss 中位数 1.44（其他会议约 0.35），音频能量与标注相关系数 0.02，判定音频与标注不匹配并隔离；合成 dense 档 loss 中位数 0.73、11% 超过全局 p99，判定为难以学习的目标并移除。001–003 失败原因：验证读取改用带标点标注未链接、按子串排除误伤真实会议、模板未切训练模式。
