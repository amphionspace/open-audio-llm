# 本机双卡持续训练

输入：统一格式第 1000 步 checkpoint，以及配比修复后全部 4,023,765 条有效记录。当前机器为两张 RTX 5090 32GB。

基座选择：使用 `tasks/train/attempts/003/artifacts/training/checkpoint-1000` 的 Qwen3-ASR-1.7B 衍生模型。该模型已有本机 vLLM 固定集结果，宏平均 cpCER 21.43%，明显优于退化的 checkpoint-71000（29.34%）；它已经学习当前说话人/时间戳格式。原生预训练模型没有这项格式适配，不作为这次重新起点；旧混合模型的历史结果来自不同运行环境，不据此宣称它更优。

训练方式：LoRA rank 32、alpha 64，只训练语言模型线性层的适配器，音频编码器、对齐器与基座权重冻结。相较此前全参训练，本机显存较小；限制可训练参数也避免直接改写已经有效的音频表示。全新优化器、调度器和数据游标，不继承退化训练的状态。

数据：固定 75 个来源及版本，保留真实 clean-pass、时长、开发集隔离规则。样本占比为单人回放 20%（包括单人合成）、多人合成 40%、真实会议 40%。每来源完整读取后才循环，数据轮由全覆盖要求决定；无来源子集或训练步数上限。真实会议每覆盖轮平均约 137 次读取，这是显式重复，不算新增数据。

Loss：按每例平均的交叉熵，单人数据也采用说话人监督格式。`replay_kl_weight=0`，不加载原生 ASR 教师；不再把未实际参与 loss 的 KL 宣称为保护机制。保持依赖明确的监督回放和基座冻结，仍需固定集观测验证模型能力。

本机参数：每卡 microbatch 1、梯度累积 16，正常每更新 32 条；BF16 计算、适配器 FP32 主权重与 AdamW。峰值 LR 2e-5，500 步 warmup，随后 inverse-sqrt 衰减（timescale 10,000），不依赖总训练步数；无业务步数或 epoch 截止。允许 600 秒长会议，未为适配显存删掉长数据。

评测：每 500 步保存，首个保存点及之后每 2000 步暂停更新，CPU 合并适配器后使用 vLLM 0.18.0、TRITON_ATTN 评测固定 338 条会议及 48 条 ASR 样本的两种提示。复用已有 1000 步同机基线。评测启动单独 W&B 记录并将主要指标同步回训练 run；结果保留原始输出。训练期间模型仍驻留，评测 GPU 内存预算为 60%。

完成条件：启动必须有双 rank 参数范围/实际更新审计、有限 loss 和 W&B 远端实际训练指标；这只证明运行正确，不能等同于能力达标。后续按固定集 cpCER、tcpCER、重复/触顶率和 ASR 错误率判断质量。

验证：3 项持续调度/恢复测试、23 项 loss/优化器/评测回调测试、3 项评测同步测试通过；正式入口 dry-run 通过；75 个来源和所有权重与配比核验产物完全一致。

历史执行 001 已停止并保留：第 3,100 步日志 loss 0.268，最后完整 checkpoint 为 3,000；第 500 和 2,000 步固定集结果均优于 checkpoint-1000，未发现本阶段能力退化。但 001 实际使用的 inverse-sqrt 调度器忽略了配置的 `timescale=10000`，第 2,000 步已错误衰减到峰值一半，因此不继续沿用其优化器状态。
