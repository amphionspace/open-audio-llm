# 修复全量训练数据配比

输入：全量训练 001 的固定数据配置与实际索引，保留 4,023,765 条有效记录及原有质量、时长、开发集隔离规则。

目标：单说话人回放 20%、多人合成 40%、真实会议 40%。合成来源中的单人样本归入回放组；549 条事件样本按合成组内有效记录数量分配，不单独占 35%。这些是明确的任务预算，不是经参数扫描得出的最优比例。

实现：来源权重控制实际读取频率，沿用每例平均 CE；每个来源内部先完整遍历再循环。覆盖轮长度由最慢来源自动确定，不使用固定子集或训练步数上限。每个配比窗口内将长短 batch 打散；断点游标保留已训练位置。小来源会重复，核验报告披露实际次数；不宣称每个记录恰好一次。

完成条件：静态检查输入索引完全一致；真实采样器每个窗口达到配置比例；双卡分配后全量覆盖、遗漏为零；来源重复次数和 DDP 末批补齐单独记录。

执行：`open-audio-llm prepare --config runs/unified-diarization-asr-20261001/configs/rebalance-data.yaml`。仅 CPU 数据准备和检查，无模型训练或推理，不创建新的 W&B 模型实验。
