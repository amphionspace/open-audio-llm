  - GRPO 的提示不经过 think 配置，交付版那一轮也是 think 关。
  - think 开靠两点保住：KL 的参考模型就是起点；插值的另一端也是起点，两端都会 think。

- **守门回到交付版水平**：think 关，每项都不比交付版差。差异用配对 bootstrap（`ae open-audio-llm compare`）判断，看 95% CI。

  - 交付版的中文 TS-ASR 测试集和鼎桥机主识别用的是旧 TS 提示，这两项的差里含提示变化，与第二轮同样处理。
- **think 开可用**：同一模型 think 开减 think 关，第二轮那六项的差都不超过 0.5 个点。
- **说字保住**：think 开纠正成功率、真实挖掘准确率不明显低于第二轮 think 开（78.51%、109/127）。纠正成功率要打折看，原因见第二轮 README。
- **交付**：三项都满足的候选进入交付评估，avg3 和插值都满足时选守门更好的；都不满足就记录结果，交付版不变。

## 结果与结论（2026-11-15）

**结论**

| 能否交付 | **不能**，有两项判定没满足 | **不能** |

交付版不变。avg3 是目前最接近的带 think 候选，与交付版相比的得失见下面的守门表。

- **GRPO 把第二轮升上去的误触发压了回去**（avg3 对第二轮 think 关）：
  - GigaSpeech 无语音误触发 34.87 → 26.46（−8.41*），已低于交付版。
  - 中文 TS-ASR 测试集 CER 13.71 → 12.84（−0.87*）：漏识别 −0.77*，误触发 +0.20*。
  - asrreg 中文 CER 3.80 → 3.70（−0.10*），英文 WER 7.49 → 7.36（−0.12*）。
- **剩下的差距在中文方言**（avg3 对交付版）：
  - KeSpeech 各方言 +0.2 到 +0.4；WenetSpeech 四川话 easy +0.92*、hard +1.26*；Common Voice 中文 +0.18*；WenetSpeech test_net +0.15*。
  - aishell、aishell2、magicdata、警务等普通话朗读集基本持平。
  - 退步来自续训 SFT：第一轮对照组（同样续训、不加 think）asrreg 中文也是 +0.11*，第二轮 think 关是 +0.24。这一轮 GRPO 收回了 0.10。
  - 不是续训丢了 GRPO 学到的东西。交付版的 SFT 祖先 10.28（`ts-robust-054-avg3`，run-20261104T085228Z-c54b154a）与交付版接近：四川话 14.66 / 27.21，KeSpeech 普通话 2.32，Common Voice 中文 5.02；交付版是 14.84 / 26.94、2.28、4.84。avg3 是 15.76 / 28.20、2.42、5.02，比两者都差。
  - 续训数据里有 KeSpeech（权重 1.91），续训为什么把方言带差，没有进一步定位。
- **中文 TS-ASR 测试集误触发**：avg3 3.16，交付版 2.69，第二轮 2.96。交付版用旧 TS 提示，这项差里含提示变化。
- **插值版的守门都比 avg3 差**：插值的另一端是第二轮 checkpoint，它自己守门就差，插值等于往回退一半。交付版那一轮插值的另一端是 v9 插值，守门本来就好。
- **鼎桥普通识别，avg3 是 31.97**（交付版 18.39，差 +13.58 [−1.10, +44.36]，不显著），几乎全来自一条：
  - 参考是“请执行”重复 6 遍（18 字），avg3 写出 132 字。交付版、第二轮、插值在这条上都写到 512 token 上限，最后只剩 5 个字。
  - 第十轮的 v10 avg3 也在这一条出错（写出 89 字），见 oal-grpo `runs/amphionasr2-grpo-20261101/tasks/23-grpo-v10-from-v9interp/README.md`。
  - 其余是警务指令子集，错字数 94 → 98。
- **think 开**：
  - 上下文纠偏的 3,249 条 think 开输出全部正常闭合，没有空答案：avg3 有 2,064 条写说明、1,185 条写固定句，插值是 2,066 / 1,183。
  - 鼎桥机主识别 6 条中，avg3 有 1 条写了固定句后答案为空。其余 think 开项目与 think 关持平或更好。
- **没有再开实验**，原因如下：
  - 同配方再做一轮 GRPO：oal-grpo 第十一轮（从 v10 avg3 再做一轮）没有收益，只是在 TS 漏识别和误触发之间移动。
  - 与交付版插值：第二轮 50% 插值后 think 开已经坏了。守门大致随权重线性变化，think 还能用的权重下，中文方言仍会差于交付版。
