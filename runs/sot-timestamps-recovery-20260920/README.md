## 恢复方法

对原来 `needs_review` 的片段，在推理输入前分别补 40 ms、120 ms 静音，末尾补
160 ms 静音，再将预测时间减去前缀时长。语音样本、来源版本、裁剪范围和文字均不变。
训练仍读取原混音，不使用补静音或减速后的音频。

模型时间步长为 80 ms。新结果必须通过原有全部边界检查，字词序列必须一致，整句
首尾相对原预测的最大变化不超过两个时间步（160 ms）。不裁剪越界、不填充零时长，
不直接将旧问题标记改成通过。通过的新结果保留原标注及变换信息；其余保留原结果。
`aligned` 仍只是自动对齐检查通过，不代表人工复核或时间精度已获人工确认。

302 条诊断样本中，两种偏移有 178 条通过原检查；加入边界稳定性要求后为 165 条。
这是按来源和问题类型抽取的诊断集，不能把这个比例当作总体成功率。
减速方案没有用于全量批次；固定开发集仍未解决的来源另作精细对齐，见下文。
